# ISONORAFTER

Applies to: Calculated column Calculated table Measure Visual A boolean function that emulates the behavior of a Start At clause and returns true for a row that meets all of the condition parameters.

## Syntax

```dax
ISONORAFTER(<scalar_expression>, <scalar_expression>[, sort_order [,<scalar_expression>, <scalar_expression>[, sort_order]]…)
```
