# Background — Subtle, Non-Competing

Use a background color that supports the data without drawing attention away from it.

## Principle

The dashboard background is a stage for the data, not a participant. A subtle, neutral background lets visual elements (charts, KPIs, tables) command attention. Bold or busy backgrounds compete with the data and reduce readability — this is a direct application of [[Gestalt-Principles]] (figure-ground law).

## Guidelines

- Default: white or very light grey backgrounds
- Optional brand alignment: a subtle background based on brand colors is acceptable if it does not overpower the data
- Avoid: saturated background colors, gradients, or textures that create visual noise
