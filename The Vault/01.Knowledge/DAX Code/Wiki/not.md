# NOT

Changes FALSE to TRUE, or TRUE to FALSE.

## Syntax

```dax
NOT(<logical>)
```

## Parameters

| Term | Definition |
|------|------------|
| `logical` | A value or expression that can be evaluated to TRUE or FALSE. |

## Return Value

TRUE or FALSE.
