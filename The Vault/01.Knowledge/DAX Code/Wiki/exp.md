# EXP

Applies to: Calculated column Calculated table Measure Visual calculation Returns e raised to the power of a given number. The constant e equals

## Syntax

```dax
EXP(<number>)
```

## Remarks

EXP is the inverse of LN, which is the natural logarithm of the given number. To calculate powers of bases other than e, use the exponentiation operator (^). For more information, see DAX Operator Reference.
