# CHISQ.DIST.RT

Applies to: Calculated column Calculated table Measure Visual calculation Returns the right-tailed probability of the chi-squared distribution.

## Syntax

```dax
CHISQ.DIST.RT(<x>, <deg_freedom>)
```

## Remarks

If x or deg_freedom is nonnumeric, an error is returned. If deg_freedom is not an integer, it is rounded.
