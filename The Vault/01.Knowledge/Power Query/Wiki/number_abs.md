# Number.Abs

Returns the absolute value of number. If number is null, Number.Abs returns null. number: A number for which the absolute value is to be calculated.

## Signature

```m
Number.Abs(number as nullable number) as nullable number
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| number | nullable number | |

## Returns

nullable number

### Example 1

Absolute value of -3.

```m
Number.Abs(-3)
```

// Output
```
3
```
