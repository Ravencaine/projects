## Summary

Tony Phillips outlines six Excel features he considers essential for every workbook: Excel Tables, Data Validation, Conditional Formatting, Custom Number Formats, Slicers, and Power Query. Each one solves a recurring structural or maintenance problem — collectively they keep spreadsheets organized, accurate, and easy to share.

## Key Claims

- Excel Tables (Ctrl+T) create a self-maintaining data structure using structured references instead of fragile cell ranges
- Data Validation prevents bad data entry before it happens; includes dropdowns, boundary rules, and custom input messages
- Conditional Formatting adds a visual intelligence layer that reacts to data values without formulas
- Custom Number Formats change display without changing underlying values — abbreviations, units, zero suppression
- Slicers provide a visual, button-based filtering interface for Excel Tables and PivotTables
- Power Query records data-cleaning steps so the same transformation runs automatically on refreshed data

## Notable Details

- Custom formats and conditional formatting solve different problems — format changes display, CF reacts to data changes
- Slicers work on standard Excel Tables, not just PivotTables
- Power Query's Applied Steps pane is the key to repeatable, automated data prep
