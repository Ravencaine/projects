# ELT Pattern

<!-- A data loading pattern where transformation happens inside the target database using SQL rather than in a separate processing layer. Modern databases handle transformation efficiently; a dedicated transformation cluster may not justify the cost. -->

## Definition

A data loading pattern where transformation happens inside the target database using SQL rather than in a separate processing layer. Modern databases handle transformation efficiently; a dedicated transformation cluster may not justify the cost.
