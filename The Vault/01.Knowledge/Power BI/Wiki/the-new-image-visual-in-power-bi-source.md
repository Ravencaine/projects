# The New Image Visual in Power BI Is a Quiet Game Changer

**Level:** Beginner | **Category:** DAX, Data Visualization

## Key Capabilities

- Dynamic binding to fields, DAX measures, URLs, and SVG strings
- Layout modes: Fit, Fill, Cover, Crop, Scale responsively
- Clickable images with actions (navigation, tooltips, bookmarks, drill-through)
- Alt text front-and-center for accessibility compliance
- Sharper, faster SVG rendering — no pixel tearing
