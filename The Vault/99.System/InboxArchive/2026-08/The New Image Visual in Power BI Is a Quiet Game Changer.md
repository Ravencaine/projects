## Dynamic images, clickable actions, cleaner UI, and fully customizable visual components — this update quietly changes everything.

## Introduction

When Microsoft said they were revamping the Image visual, I was really excited, and after experimenting with it, even more by all the design options and capabilities it offers! 🤩

The new Image visual finally gives us the dynamic, flexible, pixel-perfect control we’ve needed for years.

Here’s a short demo of a visual card I created with it!

And if you also work with icons, SVGs, KPIs, navigation elements, nudges, or any kind of micro-UX inside your dashboards…  
this small update has *massive* impact on how you build reports.

Let me show you 😁!

## 🚀 1. Dynamic Images… Actually Dynamic This Time

Until now, the “Insert Image” experience was basically static wallpaper.

With the new Image visual, you can bind images to:

- **Fields**
- **DAX measures**
- **Calculated dynamic URLs**
- **SVG strings**
![](99.System/Attachments/1!mrHmdsHDueYcxeLyhQ-mZg.png.webp)

Image source settings in Power BI

This means you can finally create:

✨ Dynamic KPI icons  
✨ Status pills  
✨ Arrow indicators  
✨ Alerts or nudges  
✨ Navigation icons that react to slicers  
✨ Category-based visuals (e.g., department logos, product icons)

All without hacks, workarounds, or table visuals pretending to be image containers.

**One DAX measure → infinite visual states.**  
It’s clean, declarative, and reusable — especially if you’re using UDFs.

## 🎯 2. Perfect Fit, Fill, and Crop Controls

*No more warped logos. No more stretched icons. No more 2-px borders that annoy you for hours 😅.*

Power BI finally gives us layout modes that designers take for granted:

- **Fit**
- **Fill**
- **Cover**
- **Crop**
- **Scale responsively**
![](99.System/Attachments/1!mMaIeGS-_xH4fLgazh__oA.png.webp)

Image control capabilities in Power BI

With these, your icons, illustrations, and SVGs become **consistent** across pages, devices, and canvas sizes.

It’s a small checkbox with huge design implications.

## 🎨 3. Images Can Now Be Meaningful Visual Elements

This is the moment where the Image visual stops being decorative and becomes functional.

Examples you can build now:

- A nudge icon that appears only when a KPI needs attention
- Tooltip buttons that visually change when the user opens/ closes the help panel
- Navigation icons that highlight the current section
- Department logos that switch automatically based on user selection
- Status cards that include dynamic symbols (✔️, ⚠️, ⛔)

In other words, your “design system” inside Power BI finally has reusable, scalable image components.

## 🧭 4. Clickable Images (Navigation, Info Panels, Pop-Ups)

This one alone is worth an entire update.

![](99.System/Attachments/1!QdqLMTiVlsgqR7RyFUNM9g.png.webp)

Image clickable actions in Power BI

You can now attach **actions** to images:

- Navigate to pages
- Open tooltips
- Trigger bookmarks
- Show/hide help content
- Open pop-up overlays
- Jump to drill through pages

This replaces:

❌ Buttons  
❌ Shapes  
❌ Hacky bookmark toggles  
❌ Invisible overlays

And the best part?

Your icons remain crisp, responsive, and dynamic.

Imagine your next dashboard:

- Tiny “i” icons with dynamic colors
- A “?” help button with a subtle pulsing nudge
- A navigation bar made entirely of SVG icons
- A “Show analysis” call-out that lights up only when insights are available

These micro-interactions are what make reports **usable** — and now they’re effortless.

## ♿ 5. Accessibility Gains That Actually Matter

One of the most underrated improvements: **Alt text is now front and center.**

![](99.System/Attachments/1!dkfRM-FzzEdKNeB0AspP2Q.png.webp)

Image’s Alt text in Power BI

Images are now accessible elements with:

- Screen reader support
- Semantic meaning
- Narration capabilities

If you work with public sector, healthcare, or large enterprise clients, this is not optional — it’s expected.

## 📊 6. SVG Support Is Better Than Ever

I know many of you (myself included) rely heavily on SVGs for:

- Pills
- Arrows
- Icons
- Status lights
- Sparkline-like visuals
- Tiny scorecard elements

The new visual renders them:

- Faster
- Sharper
- More consistently
- Without pixel tearing

And since they plug nicely into **dynamic DAX measures**, this becomes one of the cleanest ways to build design-first analytical components.

## 🧱 Why This Matters More Than It Seems

Power BI has been slowly moving toward a more flexible design system:

- **Dynamic format strings**
- **User-defined functions**
- **Visual containers**
- **Custom themes**
- **Switching logic with field parameters**

The new Image visual fits right into this evolution.

It enables a whole category of micro-UX that used to require hacks, workarounds, or hours of tweaking.

Now?

**One image.  
One measure.  
One action.**

And your report suddenly feels 10× more polished 🥳.

## 📁 A Few Use Cases to Try First

Here are ideas you can implement in under 5 minutes:

### ✓ Dynamic status dots for KPIs

Change color based on rules (low risk, medium risk, high risk).

### ✓ A “Help” button with a small nudge animation

Let users discover how to read your report.

### ✓ A navigation bar made entirely of SVG icons

Highlight the active page by switching fill color.

### ✓ Category-based render

If “Department = Finance,” show the Finance icon automatically.

### ✓ Dynamic rating stars

Perfect for surveys, product feedback, or HR dashboards.

You’ll probably start using this visual **in every report**. I know I will 😅!

## 🌟 In Short

The new Image visual elevates Power BI in the same way dynamic format strings did: quietly, but fundamentally.

It gives us:

✔️ Dynamic logic  
✔️ Responsive design  
✔️ Reusable components  
✔️ Better accessibility  
✔️ Interactive micro-experiences  
✔️ Developer-grade SVG rendering

It’s not flashy.  
It’s not loud.  
But it unlocks a new layer of control over how our dashboards look and feel — and that’s the kind of upgrade that changes *everything*.
