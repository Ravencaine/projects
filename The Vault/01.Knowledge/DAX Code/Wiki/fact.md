# FACT

## Syntax

```dax
FACT(<number>)
```

## Remarks

If the number is not an integer, it is truncated and an error is returned. If the result is too large, an error is returned. This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
