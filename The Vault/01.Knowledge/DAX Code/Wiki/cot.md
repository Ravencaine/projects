# COT

Applies to: Calculated column Calculated table Measure Visual calculation Returns the cotangent of an angle specified in radians.

## Remarks

The absolute value of number must be less than 2^27 and cannot be 0. If number is outside its constraints, an error is returned. If number is a non-numeric value, an error is returned.
