# Design Inspiration Collection (Report Design)

Building a reference library of design ideas before starting a Power BI project — sourced from four platforms.

## Platforms

| Platform | URL | Access |
|----------|-----|--------|
| Dribbble | dribbble.com | Free account |
| Behance | behance.net | Free account |
| Figma Community | figma.com/community | Free account |
| Envato Elements | elements.envato.com | Paid subscription |

## Workflow

1. Search tags: `Dashboard`, `Analytics`
2. Screenshot designs that catch your eye
3. Paste into a Figma draft file for collation
4. Extract color palettes, layout ideas, typography choices

## Why

Keeps the designer creative rather than reactive — pre-loaded inspiration prevents defaulting to generic Power BI defaults.
