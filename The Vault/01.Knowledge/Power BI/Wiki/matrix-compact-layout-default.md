# Matrix Compact Layout Default Atomic

**Type:** Atomic · **KB:** Power BI · **Source:** [[source-new-matrix-visual-layouts-power-bi]]

Compact layout is the new default for Matrix visuals in Power BI (May 2024 update). It displays hierarchical data with indentation rather than separate columns — similar to the old "stepped" layout but improved. Designed to maximize visible data on screen.

## Key characteristics

- **Default**: Compact is now the default when creating a new Matrix visual
- **Indentation**: Hierarchical levels shown via indentation, not separate columns
- **Space efficient**: More data visible without scrolling
- **Excel familiarity**: Designed for users transitioning from Excel pivot tables

## When to switch away from Compact

| Layout switch | Reason |
|---------------|--------|
| Outline | When you need each hierarchy level in its own column for clarity |
| Tabular | When you want column-based layout but without blank row gaps |
