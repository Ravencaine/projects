# SIN

Applies to: Calculated column Calculated table Measure Visual calculation Returns the sine of the given angle.

## Syntax

```dax
SIN(number)
```

## Remarks

If an argument is in degrees, multiply it by PI()/180 or use the RADIANS function to convert it to radians.
