# ODDFYIELD

Returns the yield of a security that has an odd (short or long) first period.

## Syntax

```dax
ODDFYIELD(<settlement>, <maturity>, <issue>, <first_coupon>, <rate>, <pr>,<redemption>, <frequency>[, <basis>])
```
