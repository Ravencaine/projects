Generating new Excel workbooks in Power Automate — more specifically, *blank* workbooks — is a great way to build and organize basic Excel templates for future data reporting. This process results in “shell” documents that can be created with dynamic workbook & worksheet names, which (thanks to Power Automate’s seamless integration with our file system) we can directly save in a relevant folder for reporting teams.

In this quick walkthrough, we’ll learn how to generate a blank Excel spreadsheet in Power Automate (using the **Cloudmersive Document Conversion** connector) and add two new worksheets to our workbook. In this context, we’ll build an **instant cloud flow** so we can easily run a quick test with full control over our data at the end.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*p743mlPrYwaBLR7ib8KFVw.png)

Select the option to create an Instant cloud flow

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*dsi3IIsCLe_wdci9rQVAaA.png)

Select the option to trigger this flow manually

We’ll begin our flow by adding a new action and searching for Cloudmersive connectors. We’re specifically looking for the **Cloudmersive Document Conversion** connector (with the green logo).

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*I5J0wCNbDSDnlY2O6o5edA.png)

Search for the Cloudmersive Document Conversion connector

We’ll click “See more” to view the actions list, and from there, we’ll look for an action called **Create a blank Excel XLSX spreadsheet**. We’ll select it once we find it.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*jmQLKm4EDpl0wnr72aDrIA.png)

Locate the Create a blank Excel XLSX spreadsheet action

After we’ve selected this action, we’ll first need to create our Document Conversion connection before we can structure our request. We will need a premium Power Automate license to access this connector, but as long as we have that, we can use this for free with a free API key. I’m currently using this connector on a free connection; it allows a limit of 800 API calls per month with zero additional commitments.

Once we’ve created and authorized our connection, we’ll click “Show all” to view the advanced parameters. There’s only one advanced parameter to configure here — and it’s giving us the option to name the first worksheet in our blank workbook. If we ignore this parameter, we’ll get a generic worksheet name (i.e., “Sheet1”). In my example, I’m naming my initial work sheet “My First Worksheet”.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*wF1WQ295TlX7azWYofLJfA.png)

(Optional) Name the initial worksheet in your new workbook

We’ll now add one additional blank worksheet into our new Excel document with a second Document Conversion connector action. We’ll navigate back to the actions list, and from there, we’ll search for (and select) an action called **Insert a new worksheet into an Excel XLSX spreadsheet**.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*K9n327Iiq1-Ap6fmh8IqkA.png)

Search for the Insert a new worksheet into an Excel XLSX spreadsheet action

After we click “Show all” to view the advanced parameters, we’ll click on the **Input/InputFileUrl** field and select dynamic content from our **Create Blank Excel** action labeled **Body/EditedDocumentUrl**.

This temporary URL — which is extremely secure and deleted from memory after 30 minutes — is automatically generated by certain Document Conversion actions to facilitate a chain of high-speed programmatic document edits. This URL eliminates the need to send file bytes to the Document Conversion API endpoint and return modified file bytes repeatedly. We can simply pass the temporary file URL output from each document editing action in our flow to the next, and we’ll eventually download our file bytes at the end of that chain.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*4lZ70Uf8d_nYe4i8IgMJRw.png)

Pass the temporary document editing URL from the Create Blank Excel action to the Insert New Worksheet action

In this case, we’re only adding one additional worksheet, so we’ll name our worksheet (via **Input/WorksheetToInsert/WorksheetName**) and get ready to wrap up our flow. In my example, I’m naming this additional worksheet “My Second Worksheet”.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*A00zVrRJkjVdksD9m3eqVA.png)

Name the second worksheet in your new blank Excel document

To wrap up our flow, we’ll first download the latest version of our blank Excel spreadsheet from the Insert a New Worksheet action. To do that, we’ll use a separate Document Conversion action labeled **Finish editing document, and download result from document editing**.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*-7_2eJ5RAO8T6r8v3Tp7hQ.png)

Locate the Finish editing document, and download result from document editing action

We’ll simply pass the temporary URL from our Insert New Worksheet action in this request, and we’ll return the modified Excel document file bytes to our flow.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*69hR6qFHGSUD9kQnF4zI9A.png)

Pass the temporary document editing URL from the Insert New Worksheet action to the Finish Editing action to download the modified file bytes

We’ll now add a **Create file** action which uses the file bytes from our **Finish editing** step to generate a new blank Excel document in our file system. We can use any naming convention we want here; in my example, I’ll simply write in the name “New Blank Workbook.xlsx”.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*v1WnG1lbCCD9Ciatu_ZAoA.png)

Add a Create file action that generates the new Excel workbook using file bytes downloaded by the Finish Editing action

After we save and test our flow, we’ll find our new Excel workbook in the folder we selected with two blank worksheets.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*Xsvk-rS7IDY-gNyfftsbUQ.png)

Save and test the flow

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*cOIipL8dfycuJajpdazGNQ.png)

Locate the new blank workbook in the target folder

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*uGrNymJ2abOusc2TMLKFPw.png)

Check that the document contains two blank worksheets

And we’re all done! We can now easily generate blank Excel template workbooks and seamlessly place them anywhere in our folder system.
