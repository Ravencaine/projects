# COS

Applies to: Calculated column Calculated table Measure Visual Returns the cosine of the given angle.

## Syntax

```dax
COS(number)
```

## Remarks

If the angle is in degrees, either multiply the angle by PI()/180 or use the RADIANS function to convert the angle to radians.
