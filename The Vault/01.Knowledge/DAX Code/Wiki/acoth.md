# ACOTH

Applies to: Calculated column Calculated table Measure Visual calculation Returns the inverse hyperbolic cotangent of a number.

## Syntax

```dax
ACOTH(number)
```

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
