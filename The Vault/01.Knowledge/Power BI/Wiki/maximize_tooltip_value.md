# Maximize Tooltip Value

<!-- tooltips should provide genuinely useful additional context — not just duplicate the default fields shown on the visual -->

## Definition

Tooltips are automatic in Power BI but often underused. Deliberately design them to add context the visual cannot show: additional data fields, sparklines, or customized content via a tooltip page.

## Key Points

- Ask: what additional data fields would help the user understand this data point better?
- Consider adding a sparkline (mini line chart) in the tooltip to show the trend for that category
- Use a dedicated tooltip page to embed a full visual inside the tooltip — but only when it genuinely adds value
- Not every tooltip needs to become a mini dashboard — intentional design over auto-generation
