# Schema-on-Read vs Schema-on-Write Distinction

<!-- Data lakes use schema-on-read (structure applied at query time) while data warehouses use schema-on-write (structure enforced at load time); modern architectures use both approaches depending on data lifecycle stage. -->

## Claim

Data lakes use schema-on-read (structure applied at query time) while data warehouses use schema-on-write (structure enforced at load time); modern architectures use both approaches depending on data lifecycle stage.
