# Value.Multiply

Returns the product of multiplying value1 by value2. An optional precision parameter may be specified, by default Precision.Double is used. --- PAGE 1321 ---

## Signature

```m
Value.Multiply(
value1 as any,
value2 as any,
optional precision as nullable number
) as any
```

| Parameter | Type | Description |
