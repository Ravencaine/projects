## Summary

Collection of data visualization best-practice tips applicable to Power BI, Tableau, or any BI tool. Covers: (1) know your audience, (2) be aware of different dashboard types, (3) overview of data types, (4) which charts work best for which purposes, (5) make the best use of space, (6) refine the design and listen to user feedback, (7) examples of good and bad dashboards.

## Key Claims

1. **Know your audience:** design decisions flow from who reads the dashboard
2. **Different dashboard types:** operational, strategic, and analytical dashboards have different requirements
3. **Data types:** nominal, ordinal, interval, ratio — each suits different chart types
4. **Chart → purpose fit:** pie for part-to-whole, bar for ranking, line for trends over time, scatter for correlation
5. **Space efficiency:** make the best use of canvas; avoid both clutter and excessive whitespace
6. **Iterate with user feedback:** refine design based on how users actually read the dashboard
7. **Good vs bad examples:** concrete before/after comparisons sharpen the principles
