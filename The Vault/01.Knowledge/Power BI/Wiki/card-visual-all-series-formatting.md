# All-Series Batch Formatting

Formatting options under `Visual` → `Callout values`, `Reference labels`, `Cards`, and `Images` all offer a `Series` selector at the top. Selecting `All` applies the same setting to every callout value or reference label simultaneously.

Use `All` to:
- Set font, size, color, unit display uniformly across all cards
- Turn off background/border for all cards at once
- Position all images identically (e.g. `Left to Text`)

Use per-series selection to override individual exceptions.

**Layout options** under `Visual` → `Layout`: single row, single column, or grid; also controls card spacing.
