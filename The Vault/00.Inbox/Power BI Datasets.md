It is a common and a smart method to host your models in one central place. Where your users can connect to a model and make reports. In the past, the best option was the Analysis Services either an on-premises or a cloud version. Now you can choose the **Power BI datasets**.

It works like the AS tabular model which you can establish a live connection to; you are connecting from the Power BI Desktop and create a report for example. A process of creating a model is pretty simple. You build a model like a standard report in Power BI Desktop and upload it to the Power BI service. You can connect to a model and work through Visual Studio, Tabular Editor, SQL Server Management Studio and of course Power BI Desktop.

When you want to use the uploaded model, you pick a **Power BI datasets** functionality from the **Data** section.

![](https://miro.medium.com/v2/resize:fit:1112/format:webp/1*RPU36o_9LKZtAYhrIQjF-Q.png)

Select a dataset.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*gxzLRHrKO69xdNJCIxGCog.png)

Now, you are connected live to the dataset model. Therefore, you can make reports as well as you are connected to a SSAS/AS tabular model.
