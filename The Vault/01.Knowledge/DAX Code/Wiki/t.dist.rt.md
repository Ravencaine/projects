# T.DIST.RT

Applies to: Calculated column Calculated table Measure Visual calculation Returns the right-tailed Student's t-distribution.

## Syntax

```dax
T.DIST.RT(X,Deg_freedom)
```

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
