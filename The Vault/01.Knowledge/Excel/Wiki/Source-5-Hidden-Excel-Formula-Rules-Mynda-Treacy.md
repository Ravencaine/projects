# 5 Hidden Excel Formula Rules — My Online Training Hub / Mynda Treacy

Source: My Online Training Hub. Published 2025-12-02. Author: Mynda Treacy — already in vault.

## Summary

Five "hidden" Excel formula rules used by professionals: (1) use helper columns for readability and maintainability, (2) Boolean logic replaces IF statements, (3) LET adds inline variables for readability, (4) LAMBDA turns formulas into reusable custom functions, (5) think in arrays not rows with dynamic array functions.

## The Five Rules

| # | Rule | Technique |
|----|------|-----------|
| 1 | Build for Humans | Helper columns for auditability, maintainability |
| 2 | Boolean Logic | `=D5*G5*F5` replaces `=IF(F5, D5*G5, 0)` |
| 3 | LET Function | Inline variables for named intermediate steps |
| 4 | LAMBDA | Save formula as custom function via Name Manager |
| 5 | Think in Arrays | FILTER + SORT + spill ranges; use # reference for spilled array |
