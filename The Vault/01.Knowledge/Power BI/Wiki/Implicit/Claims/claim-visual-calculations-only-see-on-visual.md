# Visual calculations can only reference values on the visual

<!-- Visual calculations in Power BI can only reference values that are present on the visual -- even if those values are hidden. They cannot access model-level measures or columns not placed on the visual. -->

## Claim

Visual calculations in Power BI can only reference values that are present on the visual -- even if those values are hidden. They cannot access model-level measures or columns not placed on the visual.
