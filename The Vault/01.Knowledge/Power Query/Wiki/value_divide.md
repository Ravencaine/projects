# Value.Divide

Returns the result of dividing value1 by value2. An optional precision parameter may be specified, by default Precision.Double is used. --- PAGE 1312 ---

## Signature

```m
Value.Divide(
value1 as any,
value2 as any,
optional precision as nullable number
) as any
```

| Parameter | Type | Description |
|-----------|------|-------------|
| value1 | any | |
| value2 | any | |
| optional precision | nullable number | |

any
