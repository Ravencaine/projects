# ATANH

Applies to: Calculated column Calculated table Measure Visual calculation Returns the inverse hyperbolic tangent of a number. Number must be between -1 and 1

## Syntax

```dax
ATANH(TANH(number)
```

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
