# List.Split

Splits list into a list of lists where the first element of the output list is a list containing the first pageSize elements from the source list, the next element of the output list is a list containing the next pageSize elements from the source list, and so on. --- PAGE 785 ---

## Signature

```m
List.Split(list as list, pageSize as number) as list
```

| Parameter | Type | Description |
|-----------|------|-------------|
| list | list | |
| pageSize | number | |

## Returns

list
