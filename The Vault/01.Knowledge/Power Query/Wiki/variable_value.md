# Variable.Value

Returns the value of the specified variable identifier defined by the current evaluation environment. If the variable is not defined, an error is raised. --- PAGE 1337 ---

## Signature

```m
Variable.Value(identifier as text) as any
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| identifier | text | |

## Returns

any
