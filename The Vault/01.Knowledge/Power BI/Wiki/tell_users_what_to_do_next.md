# Tell Users What to Do Next

<!-- after the insight, guide the user to the next logical step — use action buttons with dynamic text -->

## Definition

A chart that ends with an insight but no action leaves the user without direction. Add action buttons with dynamic text that guide users to the next relevant page or drill-down, making the dashboard feel strategic rather than static.

## Key Points

- A static dashboard answers "what happened?" — a strategic dashboard also answers "what should I do?"
- Use a button to navigate to the next relevant page with context-aware text: "Explore early attrition drivers" vs "View regional breakdown"
- Make button text dynamic using DAX so it reflects the specific insight shown (e.g., "⚠ Early attrition in Sales (APAC) → Explore drivers")
- This closes the insight-to-action loop and makes the report feel like a guided journey
