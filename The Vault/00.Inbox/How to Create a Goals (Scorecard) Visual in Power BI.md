## 1\. Use the “Scorecard” Feature (Power BI Service)

- Go to Power BI Service ([app.powerbi.com](http://app.powerbi.com/))
- Click Goals in the left pane
- Create a new Scorecard
- Add Goals, define Current values, Targets, Status rules, and Owners
- You can also connect data from reports or manually input values

## 2\. Use a Custom Visual (if in Power BI Desktop)

- Import a custom visual from AppSource like Bullet Chart or KPI Chart
- Drag metrics like “Actual Sales”, “Target Sales”, etc.
- Define formatting to show performance bars vs targets
![](https://miro.medium.com/v2/resize:fit:1400/format:webp/0*2o1emRFTRodcRZ4-)

## 🔹 Visual Suggestions for Goals Tracking

1. KPI Visual — For one value vs target
2. Bullet Chart — Compact view of actual vs target with performance zones
3. Gauge Chart — For visualizing progress toward a target
4. Line + Column Chart — To compare trends of goals and actuals over time
5. Card Visuals with Conditional Formatting — Simple but effective

## ✅ Best Practices

- Always include time context (monthly, quarterly, etc.)
- Use conditional formatting to show Red/Green/Yellow status
- Keep goal names and labels concise
- Combine with slicers for department-wise or region-wise goal tracking
