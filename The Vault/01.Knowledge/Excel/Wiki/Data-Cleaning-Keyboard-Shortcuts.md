# Data Cleaning Keyboard Shortcuts

Seven keyboard shortcuts that reduce mouse clicks during data cleaning workflows — covering table creation, pattern fill, find/replace, navigation, filtering, and auto-sum.

## The Shortcuts

| Shortcut | What it does | Used in step |
|---------|-------------|-------------|
| **Ctrl + T** | Convert range to Excel Table | 6 — Convert to Table |
| **Ctrl + E** | Trigger Flash Fill | 2–4 — Pattern fill |
| **Ctrl + H** | Open Find & Replace | 2–4 — Replace placeholders |
| **Ctrl + Arrow Keys** | Jump to the edge of the data in any direction | 7 — Verify totals |
| **Ctrl + Shift + L** | Toggle Filters ON/OFF | 5 — Filter to blanks |
| **Alt + =** | Insert AutoSum on the selected cell | 7 — Verify totals |
| **F4** | Repeat the last action | Any — apply the same fix to adjacent columns |

## Ctrl + Arrow Keys Navigation

With a cell selected in a data range, **Ctrl + Arrow** jumps to the last non-blank cell in that direction. Combined with **Shift** (**Ctrl + Shift + Arrow**) selects the entire range from the current cell to the edge — useful for selecting all data before applying a transformation.

## Ctrl + Shift + L (Toggle Filters)

Applies or removes AutoFilter arrows on the header row. Same as: **Data → Filter**. Useful for quickly scanning unique values or filtering to blank cells (step 5 of the checklist).

## F4 — The Repeat Button

F4 repeats the last action (edit, format, paste). After applying `=TRIM()` to column A, press **F4** after selecting column B to repeat the same formula application — without re-opening the dialog.
