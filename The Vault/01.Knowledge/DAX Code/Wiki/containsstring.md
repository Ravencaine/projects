# CONTAINSSTRING

Returns TRUE if a text string contains a specified substring. Case-insensitive by default.

## Signature

```dax
CONTAINSSTRING(<withinText>, <searchText>)
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `withinText` | String | The text to search within |
| `searchText` | String | The substring to look for |

## Returns

`TRUE` if `searchText` is found within `withinText`; otherwise `FALSE`.

## Examples

**Detect "no alerts" message to toggle icon (Bittar alerts pattern):**
```dax
Alert Icon =
    IF(
        CONTAINSSTRING([Alert Message], "No new alerts"),
        [_const Icon No Alert],
        [_const Icon Alert]
    )
```

**Flag rows containing a keyword:**
```dax
Has Warning =
    IF(
        CONTAINSSTRING(MAX('Log'[Message]), "WARNING"),
        "⚠ Warning",
        "OK"
    )
```

**Use inside FILTER for string-based filtering:**
```dax
Product Filter Measure =
    CALCULATE(
        [Total Sales],
        FILTER(
            ALL('Product'[Product Name]),
            CONTAINSSTRING('Product'[Product Name], [Search Term])
        )
    )
```

## Notes

- `CONTAINSSTRING` is case-insensitive — use `SEARCH` instead if case sensitivity is needed (SEARCH returns the position; wrap with `IFERROR` to convert to boolean).
- In Bittar's alerts pattern, the alert message is generated by a DAX measure that concatenates region names. If all regions have values within threshold, the message reads "No new alerts." `CONTAINSSTRING` detects this to switch between an alert icon and a "all clear" icon.
- `CONTAINSSTRING` can be used inside `FILTER()` to filter a table based on a text substring.
- Performance: on large text columns, `CONTAINSSTRING` can be slow. Use it in a measure rather than as a calculated column on large tables.
