# CONCATENATEX

Applies to: Calculated column Calculated table Measure Visual Concatenates the result of an expression evaluated for each row in a table.

## Syntax

```dax
CONCATENATEX(<table>, <expression>[, <delimiter> [, <orderBy_expression> [,<order>]]...])
```
