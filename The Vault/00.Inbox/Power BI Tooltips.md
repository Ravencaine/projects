Power BI by default gives you basic tooltips, which present you with the values included in your visual

These are limited initially to the fields and values that have been used in creating that visual

You can easily add other fields by dragging them to the tooltips area in the visualizations panel (yes I know that’s the US spelling, but thats what it is named in Power BI)

## Setting up Power BI Tooltips

This video guide walks you through the steps to set up visual tooltips in Power BI

step 1 is to create a visual tooltip page, which is like a smaller page designed to be used as a pop up visual tooltip

![](https://miro.medium.com/v2/resize:fit:1390/format:webp/0*4CsnFRarK5t9-zCt.png)

Then on to step 2, where we activate the tooltip.

This involves going into the page information tab and setting it to be a tooltip page

![](https://miro.medium.com/v2/resize:fit:1100/format:webp/0*sp8JPmiZ-Zfe6Axs.png)

Following this, the final step is set up which visuals will use this tooltip

Here we go to the tooltip settings for each visual and select the name of the visual tooltip page that we created, and we repeat this for each visual this tooltip is to apply to

Visual tooltips in Power BI bring a rich user experience, giving your users the ability to explore what is behind the data

It brings a real WOW factor and is a very efficient way to present further details

**Doing Power BI tool tips well can really make your reports stand out and increase user engagement**
