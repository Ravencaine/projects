Here, we’ll talk about the different types of Power Automate flow.

- Microsoft Power Automate web ([***https://make.powerautomate.com/***](https://make.powerautomate.com/))
![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*06DUGwa6FWtp_4NF87tymw.png)

### Type of flows:

- **Automated Flow:** Depending on the type of Automated Flow trigger you select, an Automated Flow is advised when you want a flow to execute if certain circumstances are satisfied

**Example**: If you want to create a flow that runs whenever a user creates a new item in a SharePoint list, create an automated flow with the “When an item is created” trigger and specify the SharePoint list

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*oQeJZ9DRdz6RDM-K2uzZ8Q.png)

Automated flow

- **Instant Cloud Flow**: Given that it is in the list of triggers accessible for Instant Flow, Instant Flow is ideal for Power Apps apps and whenever you want the flow to run quickly after an action

**Example**: If want to create a Power Apps application that performs an action after a user clicks a button. This is where you need a Power Apps trigger

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*iQ6xs_fr1NVNG6mONtbfGA.png)

Instant cloud flow

- **Schedule Flow:** When you wish to schedule the flow to run at a particular time and date, this form of flow works well

**Example**: If you want to create a flow that runs every day at 10:00 AM, Schedule Flow is perfect for you

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*q--JgtWLvzMSE4VAlnsRwA.png)

Scheduled cloud flow

You can set the repeat event at every minute, hour, day, week, etc.

![](https://miro.medium.com/v2/resize:fit:1100/format:webp/1*3_0S62KzAuP3r7dyKGLdYw.png)

- **Desktop Flow:** Power Automate Desktop comes with a tonne of “Actions” that are ready to automate a variety of tasks or programs right out of the box. For instance, you could wish to automate an email that is sent when a certain event occurs. Alternatively, you could want to take the data from an Excel spreadsheet and put it in another location, like an Azure database
![](https://miro.medium.com/v2/resize:fit:1152/format:webp/1*1UEgKS-xWjyKMIkw0Gk2Lg.png)

You can install Power Automate desktop on your PC, or if you’re using Windows 11, it comes with the Flow app pre-installed. It can be used as a web scrapper find the video tutorial [here](https://www.youtube.com/watch?v=GaT4ZEBzO_I&t=9s&ab_channel=Ravi%27scontent).
