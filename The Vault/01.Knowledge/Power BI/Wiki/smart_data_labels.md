# Smart Data Labels — Highlight Only What Matters

<!-- data labels should not be all-or-nothing — show labels only on max, min, or anomaly values -->

## Definition

Data labels are often treated as all-or-nothing (on or off). A smarter approach is to show labels only on the values that matter most: maximum, minimum, latest, or anomalies.

## Key Points

- Adding labels to every bar/point creates noise — it duplicates the axis
- Show labels on the maximum (highest performer) and minimum (lowest performer) to guide attention
- Show the latest value in a time series to anchor the current period
- Anomalies flagged by anomaly detection can also carry labels
- This is a hybrid between axis labels and full data labels — selective and intentional
