# UTCTODAY

Applies to: Calculated column Calculated table Measure Visual calculation Returns the current UTC date.

## Syntax

```dax
UTCTODAY()
```

## Remarks

UTCTODAY returns the time value 12:00:00 PM for all dates. The UTCNOW function is similar but returns the exact time and date.
