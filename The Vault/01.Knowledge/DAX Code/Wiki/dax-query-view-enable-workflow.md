# DAX Query View Enable Workflow

**Type:** Workflow · **KB:** DAX Code · **Source:** [[source-dax-query-view-power-bi]]

Enable the DAX Query View preview feature in Power BI Desktop.

## Prerequisites

- Power BI Desktop updated to **November 2023 or later**
- If no update available, update Power BI Desktop first from microsoft.com

## Step 1 — Open Options

1. Open Power BI Desktop
2. Click **File** menu
3. Select **Options and settings**
4. Click **Options**

## Step 2 — Navigate to Preview Features

1. In the Options window, click **Preview features** in the left panel
2. Locate the list of available preview features

## Step 3 — Enable DAX Query View

1. Find the checkbox labeled **DAX Query View**
2. Tick/check the checkbox
3. Click **OK** to confirm

## Step 4 — Restart Power BI Desktop

1. Close Power BI Desktop completely
2. Reopen Power BI Desktop
3. The DAX Query View tab should now appear on the left side (fourth icon from top)

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Tab not visible after restart | Verify checkbox is ticked in Options → Preview Features |
| "Feature not found" | Update Power BI Desktop to November 2023+ |
| Feature disappears | May still be preview; check for updates |
