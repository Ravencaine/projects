# DAX Query View November 2023 Preview Feature Atomic

**Type:** Atomic · **KB:** DAX Code · **Source:** [[source-dax-query-view-power-bi]]

DAX Query View was introduced as a **preview feature** in the November 2023 Power BI Desktop update. It does not appear automatically — it must be explicitly enabled in Options. It remains a preview feature; non-preview GA release timing is not specified.

## How to enable

1. Open Power BI Desktop
2. Go to **File** → **Options and settings** → **Options**
3. Navigate to **Preview features** tab
4. Tick **DAX Query View**
5. Click **OK**
6. **Restart Power BI Desktop:** required for the feature to appear

## Where to find it after enabling

DAX Query View appears as a tab on the left-hand side of the Power BI Desktop interface, typically the fourth icon down. If not visible after restart, double-check the Preview features tab in Options.

## Version requirement

Requires **November 2023 update or later**. Update Power BI Desktop before attempting to enable.
