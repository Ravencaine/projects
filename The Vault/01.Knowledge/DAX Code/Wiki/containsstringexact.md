# CONTAINSSTRINGEXACT

Applies to: Calculated column Calculated table Measure Visual Returns TRUE or FALSE indicating whether one string contains another string.

## Syntax

```dax
CONTAINSSTRINGEXACT(<within_text>, <find_text>)
```

## Remarks

CONTAINSSTRINGEXACT is case-sensitive.
