# NORM.DIST

Applies to: Calculated column Calculated table Measure Visual calculation Returns the normal distribution for the specified mean and standard deviation.

## Syntax

```dax
NORM.DIST(X, Mean, Standard_dev, Cumulative)
```

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
