# Accessibility in Power BI Visual Design

Three accessibility pillars to apply when designing Power BI reports and dashboards.

## Readability

Choose font sizes and weights that ensure text is legible at typical viewing distances. Minimum body text: 10pt for dense reports, 12pt+ for executive summaries.

## Color Contrast

Check contrast ratios between background and text/visual elements using WCAG guidelines (minimum 4.5:1 for normal text). Power BI's built-in color picker shows contrast warnings.

## Color Blindness Considerations

- Don't rely on color alone to convey meaning — pair with patterns, labels, or icons
- Use direct labeling on chart segments where possible
- Test the report in grayscale to verify information is still distinguishable
- Common tool: [Color Oracle](https://colororacle.org/) for live grayscale simulation
