# LOG

Applies to: Calculated column Calculated table Measure Visual calculation Returns the logarithm of a number to the base you specify.

## Syntax

```dax
LOG(<number>,<base>)
```

## Remarks

You might receive an error if the value is too large to be displayed. The function LOG10 is similar, but always returns the common logarithm, meaning the logarithm for the base 10.
