# INFO.VIEW.RELATIONSHIPS

INFO.VIEW.RELATIONSHIPS contains information about the relationships in the model, such as the to and from table and columns, cardinality, and cross filter direction. DAX

## Syntax

```dax
INFO.VIEW.RELATIONSHIPS()
```
