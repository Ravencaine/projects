# Data Analyst Responsibilities in the AI Workflow

A data analyst connects data to insights: they connect, explore, visualise, analyse, and maintain Power BI deliverables.

## Definition

In the AI context, the data analyst is the key persona the book targets. Their responsibilities span the full data science process: defining use cases, acquiring and preparing data, building visualisations, deploying AI features in reports, and maintaining the outputs.

## Key Points

- **Connect** to data — use Power BI connectors or Azure data pipelines
- **Explore** data — EDA using data profiling tools and visualisations
- **Visualise** data — build reports and dashboards
- **Analyse** data — apply AI features (forecasting, anomaly detection, Q&A)
- **Deploy and maintain** Power BI deliverables

The analyst doesn't need to be a data scientist, but understanding ML concepts (supervised vs unsupervised, regression vs classification) is essential for choosing the right AI feature.
