# ACOSH

Applies to: Calculated column Calculated table Measure Visual calculation Returns the inverse hyperbolic cosine of a number. The number must be greater than or

## Syntax

```dax
ACOSH(COSH(number)
```

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
