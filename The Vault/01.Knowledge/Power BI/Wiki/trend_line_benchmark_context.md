# Add Trend Lines or Benchmarks for Context

<!-- add a trend line, moving average, or constant line to show how individual values compare to the whole -->

## Definition

Add supplementary line elements (trend lines, moving averages, constant lines at the average) to a chart so users can immediately see which categories perform above or below a reference value.

## Key Points

- A constant line at the overall average turnover rate lets users spot above/below-average departments in one look
- Trend lines smooth out noise in time-series data to reveal direction
- Moving averages (7-day, 30-day) help distinguish signal from short-term fluctuation
- These elements add interpretive context without making the chart noisy
- Power BI supports trend lines on line charts and constant lines on most chart types
