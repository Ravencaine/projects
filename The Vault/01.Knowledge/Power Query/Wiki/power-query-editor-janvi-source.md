## Summary

Beginner's guide to Power Query Editor: the data preparation workspace inside Power BI Desktop. Covers the five core UI components (Ribbon, Queries pane, Data Preview, Applied Steps, Formula Bar), six transformation categories (structure, cleaning, data type, combining, calculated columns, filtering/grouping), the standard workflow (Connect → Assess → Transform → Load), and why Applied Steps change everything (automated, repeatable, monthly refresh).

## Key Insight

Power Query Editor sits between data sources and Power BI reports. Every transformation is recorded as a step. Next month, refresh the data — all transformations apply automatically. The manual cleanup that used to take hours runs in seconds.
