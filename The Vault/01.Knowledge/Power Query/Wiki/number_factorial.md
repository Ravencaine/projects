# Number.Factorial

Returns the factorial of the number number.

## Signature

```m
Number.Factorial(number as nullable number) as nullable number
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| number | nullable number | |

## Returns

nullable number

### Example 1

Find the factorial of 10.

```m
Number.Factorial(10)
```

// Output
```
3628800
```
