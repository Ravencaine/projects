# DateTimeZone.LocalNow

Returns a datetimezone value set to the current date and time on the system. The returned value contains timezone information representing the local timezone. Related content Local, fixed, and UTC variants of current time functions --- PAGE 606 ---

```m
DateTimeZone.LocalNow() as datetimezone
```
