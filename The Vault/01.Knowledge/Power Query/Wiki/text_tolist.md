# Text.ToList

Returns a list of character values from the given text value text. Example Create a list of character values from the text "Hello World". Usage Power Query M Text.ToList("Hello World") Output powerquery-m{ "H", "e", "l", "l", "o", " ", "W", "o", "r", "l", "d" } Last updated on 03/24/2026 --- PAGE 1236 ---

## Signature

```m
Text.ToList(text as text) as list
```

| text | text | |
