# Dashboard as App Landing Page

Using a Power BI dashboard as the entry point for a Power BI App — replacing a blank or report-first experience with a guided, button-driven navigation hub.

## Definition

Setting a dashboard as the first screen users see when they open a Power BI App, using text boxes and buttons as navigation links to specific reports within the app.

## Why Use a Dashboard as a Landing Page

Power BI apps can contain multiple reports, which can overwhelm new users or make navigation unclear. A purpose-built landing dashboard provides orientation and one-click access to the right report.

## Elements of an Effective Landing Dashboard

| Element | Purpose |
|---------|---------|
| **Text box** | Welcome message, app description, usage instructions |
| **Button text boxes** | Action-oriented labels ("Explore Customer Data", "View Sales Report") with custom links |
| **Intentional spacing** | Clean whitespace separates sections; avoids visual clutter |
| **Branding** | Custom theme consistent with company identity |

## How to Add Button Navigation

1. Insert a **Text box** on the dashboard
2. Type the button label (e.g., "Customer Analysis →")
3. Highlight the text and click the **Link icon** in the text box toolbar
4. Select **Dashboard or report** and choose the target report
5. Repeat for each navigation option

## Making It the App Landing Page

1. Publish the app with the landing dashboard included
2. In the **Power BI Service → App settings → Navigation**: set the landing page to the desired dashboard
3. Users who open the app land directly on the dashboard first
