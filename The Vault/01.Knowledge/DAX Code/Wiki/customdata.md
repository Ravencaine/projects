# CUSTOMDATA

Applies to: Calculated column Calculated table Measure Visual calculation Returns the content of the CustomData property in the connection string.

## Syntax

```dax
CUSTOMDATA()
```

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
