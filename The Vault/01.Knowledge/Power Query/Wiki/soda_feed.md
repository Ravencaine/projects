# Soda.Feed

Returns a table from the contents at the specified URL url formatted according to the SODA 2.0 API. The URL must point to a valid SODA-compliant source that ends in a .csv extension. --- PAGE 398 ---

## Signature

```m
Soda.Feed(url as text) as table
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| url | text | |

## Returns

table
