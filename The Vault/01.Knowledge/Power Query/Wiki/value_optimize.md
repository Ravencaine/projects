# Value.Optimize

When used within Value.Expression, if value represents a query that can be optimized, this function indicates that the optimized expression should be returned. Otherwise, value will be passed through with no effect. --- PAGE 1324 ---

## Signature

```m
Value.Optimize(value as any) as any
```
