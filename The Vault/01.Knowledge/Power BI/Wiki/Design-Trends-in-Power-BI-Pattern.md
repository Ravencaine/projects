# Design Trends in Power BI — Pattern Reference

> **Type:** pattern
> **Routed to:** Power BI
> **Primary source:** Isabelle Bittar — 2024-03-02

## Principle

> The popular designs we see in apps today shape what people expect from everything they use — including dashboards and Power BI reports. Staying updated with web and app design trends is key to keeping users happy.

## Key Trends

### 1. Light Mode Comeback

Dark mode remains popular, but light mode has resurged as a clean, vibrant alternative.

**Action:** Offer both themes; let users choose. Consider light mode as the default if your audience skews toward traditional business users.

### 2. Responsive Design

Modern reports must work across devices:
- Desktop monitors
- Large boardroom screens
- Tablets
- Smartphones

**Action:** Design with responsive layouts; test at multiple screen sizes.

### 3. Bold Typography

Thin/light fonts increasingly replaced by bold fonts in user applications. Bold = improved readability and attention-drawing.

**Action:** Use bolder weights for headings and KPI labels. Reserve lighter weights for secondary text only.

### 4. Micro-Interactions

Subtle animations and visual feedback that enhance the experience:
- Chart animations on data load
- Button hover effects
- Transitions between pages
- Notifications and alerts

**Action:** Add purposeful animations — not decorative ones. Micro-interactions should provide feedback, not distract.

### 5. Expanding Color Palettes

Color trends evolve. 2024's Pantone Color of the Year was "Peach Fuzz" — warm, approachable palettes replacing cold/clinical palettes.

**Action:** Consider warmer accent colors in your palette. Match brand colors when appropriate.

## Design Trend Adoption Checklist

| Trend | Consider When |
|-------|--------------|
| Light mode | Audience is traditional business users; mixed-device environments |
| Responsive | Reports must work on mobile/tablet |
| Bold typography | Reports with many headings and labels; readability is critical |
| Micro-interactions | Reports with drill-downs, animations, or complex user actions |
| Warm color palettes | When brand allows; when targeting general audiences |
