# Hidden Pane Fix Checklist

Quick-reference for restoring missing panes in Power Query Editor and Power BI Desktop. Covers the 5 most common scenarios.

## Power Query Editor

| Check | Path | Restores |
|-------|------|----------|
| ✅ Applied Steps pane | View → Layout → **Query Settings** | Right-side query steps panel |
| ✅ Formula Bar | View → **Formula Bar** | M code expression bar above preview |
| ✅ Parameters | View → **Parameters** | Parameter options in ribbon |
| ✅ Queries pane | Click **chevron** on left edge | Left-side query list |

## Power BI Desktop

| Check | Path | Restores |
|-------|------|----------|
| ✅ Any pane | View → **Pane Manager** → toggle | All modern panes (Filters, Data, Build, Format, etc.) |
| ✅ Minimize pane | Click **chevron** | Collapse without closing |
| ✅ Close pane | Click **ellipses (⋯)** | Remove from sidebar |
| ✅ Resize pane | Drag **resize handle** | Adjust panel width |

## Panes Available via Pane Manager

- Filters
- Data
- Build (Visualizations)
- Format
- Bookmarks
- Selection
- Performance Analyzer
- Sync Slicers
