# VaultMind

A **private, offline AI knowledge vault** desktop app. Drag-and-drop documents, videos, audio, and web URLs in; ask grounded questions; answers are generated by a local LLM using **only** the materials you've ingested.

Everything runs on your laptop. Zero cloud, zero API keys, zero telemetry.

---

## Hardware requirements

Designed for and verified on **Intel Lunar Lake / Arc 140V** laptops with **16 GB RAM**.

| Component | Minimum | Recommended |
|---|---|---|
| CPU | Intel Core Ultra (Lunar Lake or later) | Core Ultra 7 256V (8 cores) |
| RAM | 16 GB (soldered, ceiling) | 16 GB |
| iGPU | Intel Arc (any) | Arc 140V |
| Storage | 20 GB free | 100 GB free (room for many videos) |
| OS | Windows 11 22H2+ | Windows 11 Home / Pro |
| Network | Offline-only after install | Killer Wi-Fi 7 (for initial downloads) |

---

## Software prerequisites

- **Python 3.12** — `winget install Python.Python.3.12` or python.org installer.
- **Ollama 0.4+** — [ollama.com/download](https://ollama.com/download).
- **ffmpeg 6+** — `winget install Gyan.FFmpeg` or download from [gyan.dev](https://www.gyan.dev/ffmpeg/builds/).
- **Tesseract OCR** — `winget install UB-Mannheim.TesseractOCR` (only needed for image / scanned-PDF extraction).
- **Rust stable ≥ 1.82** + `cargo` — [rustup.rs](https://rustup.rs).
- **Node.js 20+** — only needed for `cargo tauri` CLI install.

> The bootstrap script (`scripts/bootstrap.ps1`) installs all of the above on Windows.

## Quick start (dev mode)

Two terminals.

**Terminal 1 — backend:**

```bash
cd VaultMind
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt
uvicorn backend.main:app --port 8765 --reload
```

**Terminal 2 — Tauri shell:**

```bash
cd VaultMind
cargo install tauri-cli --version "^2.0"
cargo tauri dev
```

The Tauri window mounts after the FastAPI `/health` endpoint returns 200.

## Build (production)

```bash
cd VaultMind
scripts\bootstrap.ps1                # one-time setup
cargo tauri build                    # produces .exe + NSIS installer
```

Output: `src-tauri/target/release/bundle/nsis/VaultMind_0.1.0_x64-setup.exe`.

## Project structure

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) and [`SPEC.md`](SPEC.md). High-level:

- `backend/` — Python FastAPI app with SQLite FTS5 retrieval + Ollama client.
- `src-tauri/` — Rust desktop shell that spawns the backend as a sidecar.
- `frontend/` — Vanilla HTML / CSS / JS UI (no framework).
- `vault/` — SQLite database + media cache (created at runtime, gitignored).
- `models/` — Ollama and OpenVINO Whisper storage (created at runtime, gitignored).
