# Brand-Aligned Color Palette (Power BI)

Extract the primary colors from the target organization's website, then extend into a full report palette using a color palette generator.

## Process

1. Inspect the organization's website (DevTools → font/color inspection)
2. Note primary brand colors (e.g., FVSD: green, light blue, dark purple, beige)
3. Input these into a palette generator (e.g., [Coolors.co](https://coolors.co/)) to generate complementary variants
4. Apply the palette consistently across the report

## Power BI Application

- Background colors
- Chart series colors
- KPI card accents
- Button and shape fills

## Why

Users respond to reports that feel native to their organization — brand alignment builds trust and reduces cognitive friction.
