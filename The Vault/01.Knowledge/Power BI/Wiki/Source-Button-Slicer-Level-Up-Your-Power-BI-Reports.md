# Button Slicer Level Up Your Power BI Reports!

A Data Bear blog post by Boniface Muchendu explaining how to use the Button Slicer (New Card visual in slicer mode) in Power BI — covering setup, styling, images, conditional formatting, and drill-down.

> **Type:** article
> **Author:** Boniface Muchendu (Data Bear)
> **Published:** 2024-01-21
> **URL:** https://databear.com/button-slicer-level-up-your-power-bi-reports/
> **Routed to:** Power BI

## Summary

The article introduces the Button Slicer — a Power BI slicer visual built from the New Card visual (preview feature) that renders filter options as interactive, styled buttons instead of a standard list. It walks through enabling the preview, building the slicer, applying shape/color/image formatting, adding conditional formatting rules, and linking buttons to drill-through pages.

## Key Claims

- The Button Slicer replaces dull list-style slicers with interactive, visually rich buttons
- The New Card visual must be enabled via File → Options → Preview features
- Buttons support four independently formatable states: Default, Hover, Pressed, Selected
- Image URL fields can be added via Call out values → Add data field
- Conditional formatting changes button appearance based on data thresholds
- Buttons can link to other report pages for drill-down navigation
- Combining Button Slicers with maps and charts creates interactive data storytelling experiences

## Notable Details

- Preview feature requirement ("New card visual") is easily missed
- The "New slicer" in the visualization pane is actually the New Card visual used in slicer mode
- Image saturation on hover provides a subtle dimming effect for selected-state feedback
