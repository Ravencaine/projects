How to Build a Clean P&L in Power BI - Select Distinct Skip to content Business Analytics Blog How to Build a Clean P&L in Power BI If you have ever exported data straight from your accounting software into a BI tool, you know it rarely looks boardroom-ready on the first try. Getting from messy ledger entries to a sleek, executive-level Profit & Loss (P&L) usually comes down to three core tools: Xero: Your source of truth for all transactions, tracking categories, and account codes. Excel: The bridge you use to structure, filter, and map out your chart of accounts. Power BI: The tool that brings it all together with dynamic measures, clean hierarchies, and a polished look. Stage 1: Xero Data Extraction Before building anything, you need to pull your raw data. Start by locating your standard Profit & Loss report directly within Xero so you have a live reference point to cross-check your numbers against. From there, you’ll need to export two core components: The Chart of Accounts: Your master list of account codes and categories. The Transaction Data: Every individual financial line item that feeds those accounts. Chart of Accounts 1. Navigate to the Accounting tab on the Xero navigation bar. 2. Select the tab to open the dropdown menu and locate Chart of Accounts under the ACCOUNTING TOOLS section. 3. Export this file, download it, and save it as an Excel Workbook Transaction Data 1. Navigate to the Reporting tab on the Xero navigation bar. 2. Locate Account Transactions under the FAVOURITE REPORTS section. (Note: If you cannot locate it from the dropdown, select All reports to find it there). 3.Select all accounts (this makes it much easier to filter in Excel) 4. Select these 13 core columns (feel free to select additional options if your reporting requires extra details) 5. Export, download, and save this file as an Excel Workbook Pro Tip: Make sure both of these files are saved explicitly as Excel workbooks (.xlsx) rather than defaulting to CSV format to preserve your data types Stage 2: Excel – Data Preparation 1. Open your Transaction Data file and delete the top 4 rows of report metadata so your table headers sit neatly on row 1 2. Select all columns, go to the Data tab, and click Filter so filter arrows appear on your top row 3.Navigate to the final column ( Account Type ) and filter it to show only Revenue and Expense (since we only want P&L-related figures) 4. Ensure the Date column is correctly formatted as a Date 5. Copy and paste this newly filtered data onto a separate, clean tab 6. Save and close the file Stage 3: Power BI Ready Data 1. Open Power BI Desktop 2. Click Excel Workbook on the Home ribbon and select your cleaned Transaction Data file 3. Ensure the correct tab containing your P&L figures is selected, then click Load 4. Repeat these steps to load in your Chart of Accounts data You should now have two tables loaded into Power BI. Next, we will bring in our mapping structures: Creating Mapping Tables 1. Navigate to Home Enter Data 2. Create your mapping tables: Table 1 (P&L Section Mapping): Enter your section names. This is vital for sorting the custom order of your P&L layout Table 2 (P&L Structure): Copy and paste the structural data template You should now have four total tables loaded into your Power BI model Determining Relationships Next, we need to connect our data model: Build a 1-to-Many relationship between your tables: ChartOfAccounts [Code] Transactions [Account Code] Troubleshooting Tip: If the relationship fails to validate at first, you may need to filter out any null values using the date column (in Power Query), then click Close & Apply Sort the P&L Mapping Table Navigate to your mapping table and sort the section column by your Custom sort order column to ensure your P&L flows logically from Revenue down to Net Profit Creating the Dynamic P&L Measure To handle standard accounts alongside calculated subtotals cleanly, create a new measure using the following DAX formula: Code snippet: This ensures that your matrix visual iterates through a true, corporate-style Profit and Loss statement layout.
