## Specialisation

1. **Component-first architecture** in Python dashboards — building reusable UI components that receive data as parameters rather than embedding it.
2. **CSS interaction without JavaScript:** using CSS 3D transforms for transitions and state changes, with Dash callbacks handling only class-toggle state.
3. **Data-driven UI:** defining card geometry and layout as data structures (tuples, lists) and rendering via list comprehension rather than imperative component code.
4. **Power BI HTML Content + Plotly.js:** embedding interactive Plotly charts (heatmaps, micro-charts) inside Power BI via DAX-generated HTML, using CONCATENATEX to bridge DAX and JavaScript.
