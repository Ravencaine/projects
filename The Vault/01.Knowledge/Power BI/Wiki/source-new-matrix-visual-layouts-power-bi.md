# Exploring New Matrix Visual Layouts in Power BI

Boniface Muchendu · Data Bear · databear.com · 2024-06-23

## What this article covers

Three new Matrix visual layouts added in Power BI May 2024 update: Compact (new default), Outline, Tabular. Setup steps for each. Cash flow / P&L report creation workflow.

## Three layouts

| Layout | Description | Best for |
|--------|-------------|----------|
| **Compact** | Indented hierarchical rows; new default | Space efficiency |
| **Outline** | Hierarchical data in separate columns; subtotals top/bottom | Familiar Excel pivot table |
| **Tabular** | Outline minus blank rows between categories | Cleaner look, space premium |

## Cash flow report steps

1. Prepare data (revenue, expenses, categories)
2. Create Matrix → Rows + Columns fields
3. Format: remove column totals, row totals bottom, rename to Subtotal / Net Profit
4. Layout: Outline or Tabular for cleaner look
