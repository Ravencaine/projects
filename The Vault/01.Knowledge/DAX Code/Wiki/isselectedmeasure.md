# ISSELECTEDMEASURE

Applies to: Calculated column Calculated table Measure Visual calculation Used by expressions for calculation items to determine the measure that is in context is

## Syntax

```dax
ISSELECTEDMEASURE( M1, M2, ... )
```

## Remarks

Can only be referenced in the expression for a calculation item. This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
