## 1\. 📋 Quick Summary of Key Metrics

Display key performance indicators (KPIs) such as:

- Total Sales
- Profit
- Customer Count
- Average Order Value 👉 Ideal for executive dashboards or overview pages.

## 2\. 🧾 Detailed Information per Selection

When a user selects a region, product, or employee, show:

- Employee Name
- Department
- Designation
- Performance Score 👉 Like a dynamic profile card or info panel.

## 3\. 🛒 Product Snapshot

When clicking on a product in a table or visual, show:

- Product Name
- Category
- Price
- Quantity in Stock
- Supplier 👉 Helps provide all product info in one glance.

## 4\. 📦 Inventory Overview

Display fields like:

- Item Code
- Location
- Quantity Available
- Reorder Level
- Last Restock Date 👉 Useful for warehouse or supply chain dashboards.

## 5\. 👨💼 Customer Information

On selecting a customer, show:

- Name
- Email
- Phone Number
- Loyalty Tier
- Lifetime Value 👉 Great for CRM-style dashboards.

## 6\. 💸 Transaction or Invoice Details

Show transaction details such as:

- Transaction ID
- Date
- Amount
- Mode of Payment
- Status 👉 A clear way to audit or highlight single-record views.

## 7\. 📊 Comparison Across Categories (with Filters)

You can filter by region, time, or department and use multi-row cards to show:

- Budget vs. Actual
- Current Month vs. Previous Month
- Target vs. Achievement

## 🧠 Tips for Using Multi-Row Cards:

- Use data labels and proper formatting for readability.
- Keep the number of fields manageable (too many can clutter the view).
- Combine with slicers or selection filters to make them dynamic.
- Works well inside tooltips or side panels for drill-throughs.
