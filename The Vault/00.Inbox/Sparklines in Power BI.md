Have you tried this new feature yet?

Sparklines are one of the new features in Power BI with the December 2021 release

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*QtRsbLwmQFR1x_JtKjYp1w.png)

Sparklines are a great little feature to provide a little added context to a headline number

If you present a table for example with a group of values for say sales

you may get asked is that good or bad?

![](https://miro.medium.com/v2/resize:fit:1100/format:webp/1*aNXBNpSI2vBXTwtDoTak9g.png)

What Sparklines do is show the trend behind these headline numbers which provide an excellent, space efficient way of showing performance over time

![](https://miro.medium.com/v2/resize:fit:1260/format:webp/1*4YB2bkArf51vG-r19g3Pew.png)

## Here is how to quickly add them to a table in the December 2021 release of Power BI Desktop

Firstly, create a table or Matrix visual

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*ObDeOJVBqGKGLfCjl6xA2Q.png)

Then with the table or matrix selected, Go to the visualisations area, right click a numeric field to use for the sparklines data. In this example ‘Sales’

Then choose add a sparkline

![](https://miro.medium.com/v2/resize:fit:1100/format:webp/1*RF8yXcxYkIeLtpaaJJhcKA.png)

**Next we need to define the X Axis**

In the dialogue box

Choose an appropriate field for the X-axis

This would typically be a date for a time series

Then click create

![](https://miro.medium.com/v2/resize:fit:1376/format:webp/1*HspLEGbNSbADbFSWf4E11Q.png)

The sparkline is added to the visual

In this example it is automatically named Sales by Date, based on the field names for the Y axis and X axis

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*x3G81BjM5bTtrkfeJhKW9g.png)

You may need to change the name using the standard options for the visual

![](https://miro.medium.com/v2/resize:fit:1100/format:webp/1*2e0QeUqkXzyiXGoIki4hNA.png)
