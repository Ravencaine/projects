# Hdfs.Files

Returns a table containing a row for each file found at the folder URL, url, and subfolders from a Hadoop file system. Each row contains properties of the file and a link to its content. --- PAGE 361 ---

## Signature

```m
Hdfs.Files(url as text) as table
```
