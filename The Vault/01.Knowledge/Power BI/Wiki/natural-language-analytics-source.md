## Summary

Power BI's natural language capabilities include the Q&A visual (for ad-hoc questions in plain English), Smart Narrative (for auto-generated analytical text summaries), and Copilot (for DAX generation and report creation). The article covers when each tool is appropriate and their known limitations.

## Key Claims

- Q&A visual converts typed questions into DAX queries against the semantic model
- Q&A requires good model preparation: synonyms, default visual type, entity recognition
- Smart Narrative summarizes visual data with context-aware analytical text
- Copilot generates entire report pages from natural language prompts

## Notable Details

- Q&A setup: Model > Manage > Synonyms — map business terms to table/column names
- Q&A can use direct DAX syntax in the question field for power users
- Smart Narrative requires the visual to be refreshed to update the narrative
