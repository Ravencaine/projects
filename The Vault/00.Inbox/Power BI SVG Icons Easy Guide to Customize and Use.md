**Power BI SVG icons** are one of the easiest ways to elevate your report design and improve user experience. These scalable, high-quality icons help create visually clean navigation buttons, add intuitive cues, and ensure clarity across all screen sizes. In this guide, you’ll learn where to find SVG icons, how to edit them in PowerPoint, and how to use them effectively in your Power BI reports.

##### What Is an SVG Icon?

**SVG** stands for **Scalable Vector Graphics**, a file format that uses mathematical formulas to render images. Unlike raster images (like PNG or JPEG), SVGs remain perfectly crisp at any size because they’re not pixel-based.

##### Why Choose SVG Over PNG or JPEG?

| Format | Best Use Case | Scales Without Loss? | File Type |
| --- | --- | --- | --- |
| SVG | Icons, logos, simple shapes | ✅ Yes | Vector |
| PNG | Backgrounds, semi-transparent effects | ❌ No | Raster |
| JPEG | Photographic detail | ❌ No | Raster |

If you’re designing icons for **Power BI navigation buttons**, SVG is the optimal choice thanks to its scalability and clarity.

##### SVG Icons in Action: Power BI Navigation Buttons

Icons aren’t just decorative they serve a critical **UX/UI function**. For instance, in a well-designed Power BI report:

- Active buttons may show a **white SVG icon**
- Inactive buttons might use a **gray or off-white version**

This contrast is more than just aesthetic. It’s a deliberate design choice that:

- Helps users orient themselves within the report
- Highlights active views or selections
- Supports accessibility and user clarity

*Icons serve as visual shortcuts users instantly associate a question mark with help, or an envelope with contact, even without text.*

##### How to Add SVG Icons to Power BI Buttons

Ready to use SVG icons in your Power BI dashboard? Here’s a step-by-step breakdown:

##### 1\. Select a Button

Click the button where you want to place the icon.

##### 2\. Open the Style Panel

In the Visualizations pane, go to **Style > Icon**.

##### 3\. Upload Your Custom Icon

- Set *Icon Type* to **Custom**
- Click **Browse**
- Select the SVG file from your device

##### 4\. Resize and Align

Adjust settings for a clean, consistent look:

- **Icon size**: 20px (recommended)
- **Image size**: Set to *Normal*
- **Padding**: Add left padding (e.g., 5px for icon, 35px for text) to ensure no overlap ![Resize and Align](99.System/Attachments/Resize_and_Align.png)

##### 5\. Repeat for Button States

Power BI allows you to set different icons for:

- **Default**
- **On Hover**
- **On Press**  
	Choose alternate SVGs (e.g., white vs. off-white) to enhance interactivity.

![Repeat for Button States](99.System/Attachments/Repeat_for_Button_States.png)

##### How to Customize SVG Icons Using PowerPoint

You don’t need Adobe Illustrator to edit SVGs. Microsoft PowerPoint offers a fast, user-friendly way to customize icons:

##### Step-by-Step Guide

1. **Open PowerPoint** → Go to **Insert > Icons**
2. Browse or search categories to find your ideal icon
3. **Change Color**: Select icon → Go to **Graphics Fill**
4. Right-click → **Save As Picture**
5. Choose **SVG** as the file format and save

PowerPoint lets you easily produce multiple color variations great for handling different states (default, hover, dark mode, etc.) in Power BI.![How to Customize SVG Icons Using PowerPoint](99.System/Attachments/How_to_Customize_SVG_Icons_Using_PowerPoint.png)

##### Where to Find Free SVG Icons

Here are two excellent (and free) sources for high-quality SVG icons:

##### 1\. PowerPoint’s Built-In Icon Library

- Launch PowerPoint
- Go to **Insert > Icons**
- Choose from hundreds of categories
- Resize and recolor as needed ![PowerPoint's Built-In Icon Library](99.System/Attachments/PowerPoint's_Built-In_Icon_Library.png)

##### 2\. Pictogrammers.com

This site hosts over 7,500 free SVG icons under the open-source **Material Design Icons** license.

##### How to Use:

- Visit the site
- Click on **Icons and Fonts**
- Choose **Material Design Icons**
- Search, browse, and **download SVG files**

You can then import them into PowerPoint for customization and export.![Pictogrammers.com](99.System/Attachments/Pictogrammers.com.png)

##### Pro Tip: Organize and Preview Your Icons

To stay efficient, create a PowerPoint “icon board”:

- Paste all your downloaded icons onto a single slide
- Rename each icon for easy reference
- Save variations (e.g., white, gray, colored, dark mode)
- When building future reports, just preview this file to identify the right icon fast
