A tooltip is a card which contains information originates from defined measures.

Here is a standard tooltip example.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*1UvqcTInsSXP_Z3vh5TWHg.png)

On a visualizations pane you can define which measures you want to place.

![](https://miro.medium.com/v2/resize:fit:1100/format:webp/1*CkHT6mPWL_nv-I_t7FNjOQ.png)

In this post, I will show you how to create an alternative tooltip version which brings additional value into your visualizations.

Here is an end result. Tooltip is comprises visualizations.

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*KjY-l8m72oultJC-PJHKnw.gif)

Step 1: Create a new tab.

Step 2: On a **Page information** section, set tooltip switch on.

Step 3: On a **Page size**, set **Type** to Tooltip.

![](https://miro.medium.com/v2/resize:fit:1100/format:webp/1*n7dydu3iDPVtmBeKR5_Cyw.png)

Step 4: On a **Page view** set **Actual size** option for a better sight.

![](https://miro.medium.com/v2/resize:fit:1100/format:webp/1*UQNegV80-n0a-b9RIjFnlQ.png)

Step 5: Create visualizations.

![](https://miro.medium.com/v2/resize:fit:1100/format:webp/1*I2adcrNWBYKWfOVrt-aFzg.png)

Step 6: Place a chosen measure in the **Tooltip** pane. From now on, always when you use an **Average Temperature** measure on any visualization and hover a mouse over the measure then a new tooltip is used instead of a standard one.

![](https://miro.medium.com/v2/resize:fit:1100/format:webp/1*s2msI0OeSimP2zKvkSBB1g.png)
