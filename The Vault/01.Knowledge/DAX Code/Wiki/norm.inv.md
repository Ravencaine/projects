# NORM.INV

Applies to: Calculated column Calculated table Measure Visual calculation The inverse of the normal cumulative distribution for the specified mean and standard

## Syntax

```dax
NORM.INV(Probability, Mean, Standard_dev)
```

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
