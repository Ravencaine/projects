## 📌 What is DAX Studio?

DAX Studio is a free, open-source tool designed to write, debug, and optimize DAX (Data Analysis Expressions) queries. It connects directly to your Power BI data model and allows you to analyze performance, inspect queries, and improve report efficiency.

## 🚀 Why Use DAX Studio with Power BI?

## ✅ 1. Query Performance Insight

DAX Studio lets you analyze which DAX measures are slowing down your report using:

- Query Plan
- Server Timings
- DMV (Dynamic Management Views)

## ✅ 2. Debug DAX Code

You can test your DAX formulas in isolation before putting them into your Power BI visuals.

## ✅ 3. Export Data

Export data directly from Power BI datasets to CSV, Excel, or SQL format — especially helpful for debugging or sharing samples.

## ✅ 4. Run Complex Queries

Sometimes, you need to perform advanced evaluations that are hard to do within Power BI visuals — DAX Studio gives you that flexibility.

## ✅ 5. Memory Usage & Model Size

You can analyze column cardinality, memory consumption, and more — useful for optimizing model performance.

## 🔌 How to Connect DAX Studio with Power BI

1. Open your Power BI Desktop report.
2. Launch DAX Studio.
3. Select “Power BI / Designer” from the connection window.
4. Start writing queries or analyzing your model.

## 🧠 Best Use Cases

- Performance tuning slow reports
- Understanding how CALCULATE, FILTER, and ALL interact
- Learning advanced DAX through query tracing
- Cleaning up unused columns or measures

## 🛠️ Must-Try Features

- Query Builder
- DMV Explorer (to view metadata)
- Query Plan Visualization
- Server Timings tab
