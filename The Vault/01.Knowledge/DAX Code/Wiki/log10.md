# LOG10

Applies to: Calculated column Calculated table Measure Visual calculation Returns the base-10 logarithm of a number.

## Syntax

```dax
LOG10(<number>)
```

## Remarks

The LOG function lets you change the base of the logarithm, instead of using the base 10.
