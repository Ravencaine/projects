## 1\. Remove Duplicates

🧹 Remove rows that appear more than once based on one or more columns.

> *Home → Remove Rows → Remove Duplicates*

## 2\. Replace Values

🔄 Quickly fix spelling errors or standardize inconsistent entries.

> *Transform → Replace Values (e.g., replace “N/A” with null)*

## 3\. Trim and Clean Text

✂️ Trim removes extra spaces; Clean removes non-printable characters.

> *Transform → Format → Trim / Clean*

## 4\. Fill Down / Up

⬇️ Fills missing values using the one above or below. Common in Excel-style tables.

> *Transform → Fill → Down / Up*

## 5\. Remove Empty / Error Rows

❌ Delete null or error-filled rows or columns.

> *Home → Remove Rows → Remove Blank Rows / Remove Errors*

## 6\. Change Data Types

🔢 Convert columns to correct types (text, number, date). Crucial for correct visuals.

> *Transform → Data Type*

## 7\. Split Column by Delimiter

🔪 Useful when data is embedded in a single column (e.g., “FirstName LastName”).

> *Transform → Split Column → By Delimiter*

## 8\. Unpivot Columns

🔄 Converts wide data to tall format — essential for time-series or repeated metrics.

> *Transform → Unpivot Columns*

## 9\. Merge Queries (Joins)

🔗 Combine data from different sources based on key columns.

> *Home → Merge Queries*

## 10\. Group By

📊 Summarize data (like total sales per region or average score per class).

> *Transform → Group By*
