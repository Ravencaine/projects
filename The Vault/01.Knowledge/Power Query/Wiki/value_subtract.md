# Value.Subtract

Returns the difference of value1 and value2. An optional precision parameter may be specified, by default Precision.Double is used. --- PAGE 1329 ---

## Signature

```m
Value.Subtract(
value1 as any,
value2 as any,
optional precision as nullable number
) as any
```
