# Cube.Measures

Returns a table containing the set of available measures within the cube. Each measure is represented as a function. Measures can be applied to the cube using Cube.AddMeasureColumn. --- PAGE 340 ---

## Signature

```m
Cube.Measures(cube as any) as table
```
