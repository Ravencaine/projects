# RANDBETWEEN

Applies to: Calculated column Calculated table Measure Visual calculation Returns a random number in the range between two numbers you specify.

## Syntax

```dax
RANDBETWEEN(<bottom>,<top>)
```

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
