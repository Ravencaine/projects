# SQL++ and N1QL: SQL for Semi-Structured JSON Data

N1QL (pronounced "Nickel") is Couchbase's SQL-like query language for JSON documents, designed to bring declarative SQL querying to NoSQL document stores.

## Definition

SQL++ is a unifying query language described in a 2014 academic paper (Ong, Papakonstantinou, Vernoux) that can query both traditional relational tables and semi-structured JSON. N1QL is Couchbase's implementation of SQL++.

Dunlop describes it as an evolution of SQL that handles nested, repeating JSON structures — the kind of data generated by web APIs, mobile apps, and IoT devices — without forcing a rigid schema.

## Key Points

- Standard SQL works on flat relational tables; N1QL extends this to nested JSON with path expressions (e.g., `person.address.city`)
- `UNNEST` operator flattens nested arrays into rows for standard SQL aggregation
- N1QL supports familiar SQL clauses: SELECT, FROM, WHERE, GROUP BY, ORDER BY, JOIN
- Couchbase's implementation is backward-compatible with standard SQL for simple queries
- SQL++ benchmark paper compared expressiveness across SQL-on-Hadoop (Hive, Impala), NoSQL (MongoDB), and NewSQL (Couchbase N1QL) systems
- The key insight: schema-on-read databases (NoSQL) need a query language as powerful as SQL to avoid requiring application-level filtering

## Examples

```sql
-- N1QL: query nested JSON document
SELECT person.name, person.address.city
FROM orders
WHERE ANY addr IN person.addresses SATISFIES addr.state = 'CA' END;
```

```sql
-- Standard SQL equivalent (flat schema)
SELECT name, city
FROM customers
WHERE state = 'CA';
```
