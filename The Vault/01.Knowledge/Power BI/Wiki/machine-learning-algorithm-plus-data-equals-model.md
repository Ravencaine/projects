# Machine Learning: Algorithm + Data = Model

Machine learning trains models not by programming rules, but by letting the model learn patterns from data.

## Definition

Machine Learning (ML) is a subset of AI where a model is trained using an algorithm and data. The algorithm defines the *type* of task (classify, regress, cluster), and the data provides the examples the model learns from. The trained model is the output.

```
Data (input) + Algorithm (input) → Trained Model (output)
```

## Key Points

- **No explicit rule programming**: the model discovers patterns itself
- The algorithm choice determines the task type: classification, regression, or clustering
- More data generally improves models, but only up to a quality plateau
- ML splits into two broad categories: **supervised** (labeled data) and **unsupervised** (no labels)

## Examples

- Predicting energy consumption (regression)
- Classifying customers as churn/no-churn (classification)
- Grouping customers by spending behaviour (clustering)
- Detecting anomalous transactions without labeled fraud data (unsupervised)
