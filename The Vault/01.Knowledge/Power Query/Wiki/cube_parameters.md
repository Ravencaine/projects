# Cube.Parameters

Returns a table containing the set of parameters that can be applied to cube. Each parameter is a function that can be invoked to get cube with the parameter and its arguments applied. --- PAGE 341 ---

## Signature

```m
Cube.Parameters(cube as table) as table
```
