# Table.PartitionValues

Returns information about how a table is partitioned. A table is returned where each column is a partition column in the original table, and each row corresponds to a partition in the original table. --- PAGE 1063 ---

## Signature

```m
Table.PartitionValues(table as table) as table
```

| table | table | |
