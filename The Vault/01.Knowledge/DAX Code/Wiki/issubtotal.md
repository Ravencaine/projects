# ISSUBTOTAL

Applies to: Calculated column Calculated table Measure Visual calculation Creates another column in a SUMMARIZE expression that returns True if the row

## Syntax

```dax
ISSUBTOTAL(<columnName>)
```

## Remarks

This function can only be used in the expression of a SUMMARIZE function.
