# ASINH

Applies to: Calculated column Calculated table Measure Visual calculation Returns the inverse hyperbolic sine of a number. The inverse hyperbolic sine is the value

## Syntax

```dax
ASINH(SINH(number)
```

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
