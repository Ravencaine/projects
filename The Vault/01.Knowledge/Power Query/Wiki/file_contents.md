# File.Contents

Returns the contents of the file, path, as binary. The options parameter is currently intended for internal use only. --- PAGE 356 ---

## Signature

```m
File.Contents(path as text, optional options as nullable record) as binary
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| path | text | |
| optional options | nullable record | |

## Returns

binary
