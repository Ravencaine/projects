# Emoji Navigation Buttons & Tooltip Nudges

Use emojis on navigation buttons and inside tooltips as visual nudges to guide user interaction.

## Navigation Button Labels

| Page | Label |
|------|-------|
| Home | 🏠 Home |
| Metrics | 📊 KPIs |
| Reports | 🧾 Reports |
| Settings | ⚙️ Settings |

Emphasize the icon: use emojis consistently with clean typography and aligned layout.

## Tooltip Nudge Pattern

```
💡 Hover here to view region-level details!
🔍 Click to drill down by department.
```

One emoji per tooltip — enough to grab attention without clutter.

## Data Literacy Nudges

Use emojis to teach new users what actions are available:

| Emoji | Meaning |
|-------|---------|
| 📘 | Informational insight |
| 🟢 | Positive / on track |
| 🔴 | Issue or alert |
| 🧭 | Next action or recommendation |

Consistent use across reports builds an organizational **visual language** — a small step toward better data culture.
