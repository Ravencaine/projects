# Clarify Metrics — Don't Assume User Knowledge

<!-- domain-specific KPIs are often misunderstood — add definitions directly on the visual -->

## Definition

Domain-specific KPIs (e.g., turnover rate, NPS, conversion rate) have multiple valid definitions. Never assume the user knows which definition is being used. Add the definition directly on the visual using an info icon with a hover tooltip, or as a subtitle.

## Key Points

- Turnover rate can mean: Leavers ÷ Ending Headcount, Leavers ÷ Average Headcount, voluntary-only, all exits — all valid, all different numbers
- Add an ℹ info icon near the chart title; hover reveals the full metric definition
- This is both a UX improvement and a governance/consistency safeguard
- In a report with multiple charts using the same KPI, define it once in a glossary page and link from each visual
