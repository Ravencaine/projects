The **Power BI glass look** is a modern report design technique inspired by the translucent, frosted-glass style introduced in recent iOS updates. By combining blurred backgrounds, semi-transparent panels, and soft visual effects, the Power BI glass look adds depth and polish to report pages without sacrificing usability. In this guide, you’ll learn how to recreate the Power BI glass look using PowerPoint and apply it as a custom background in Power BI for a clean, contemporary report design.

##### What Is the “Glass Look” in Report Design?

The glass look (sometimes referred to as glassmorphism) is a design style that mimics the appearance of looking through frosted or translucent glass. Common characteristics include:

- Blurred background imagery
- Semi-transparent panels
- Soft gradients and subtle borders
- Rounded corners and gentle shadows

When applied thoughtfully, this effect can add depth and visual interest to Power BI reports without overwhelming the data.

##### Why Use PowerPoint to Design Power BI Backgrounds?

PowerPoint might seem like an unusual choice for Power BI design, but it is actually ideal for creating report backgrounds.

Key reasons include:

- A **16:9 slide** matches the default Power BI report canvas
- Precise control over shapes, gradients, shadows, and effects
- Easy export to image formats supported by Power BI
- No need for external design software

This approach allows you to design visually rich report canvases and reuse them across multiple Power BI pages.

##### Step 1: Start with Your Existing Power BI Report

Before opening PowerPoint, take a **screenshot of your Power BI report page**. This serves as a layout guide so you know exactly where visuals such as cards, tables, and charts are positioned.

Keep in mind:

- Existing visuals may need formatting changes later
- Backgrounds and borders on visuals should be simplified
- Text colors may need adjustment for readability

Paste this screenshot into a blank PowerPoint slide for reference.

##### Step 2: Choose a Stock Image for the Background

In PowerPoint:

1. Go to **Insert > Pictures > Stock Images**
2. Choose an image with **consistent coloring**
3. Avoid images with extreme contrast or heavy detail

Images with balanced hues work best because they keep visuals readable once blurred.

Resize the image so it fully fills the slide.

##### Step 3: Create a Blurred Background Layer

To achieve the glass effect, you need two versions of the background image.

1. Duplicate the slide
2. On the first slide, select the image
3. Open **Picture Format > Picture Corrections**
4. Reduce **Sharpness to 0%**

This creates a soft, blurred image.

Next:

- Cut the image
- Set it as the **Slide Background** using *Picture or Texture Fill*
- Paste from clipboard

This locks the blurred image in place and prevents accidental movement.

##### Step 4: Overlay the Clear Image

Now:

- Copy the original sharp image
- Paste it on top of the blurred background

At this point, your slide has:

- A blurred background locked to the slide
- A clear version of the same image layered above it

This setup is essential for the glass panel effect to work correctly.

##### Step 5: Create Glass Panels for Your Visuals

Insert a **Rounded Rectangle** shape:

- Rounded corners match modern UI styles
- Size it approximately to match one report visual

With the shape selected:

- Set **Fill** to *Slide Background Fill*

Because the background is blurred, the shape now appears translucent like glass.

##### Step 6: Style the Glass Effect (Borders, Bevels, Shadows)

##### Gradient Border

- Change the line to a **gradient**
- Use white fading to light gray
- Set the gray stop to **100% transparency**

This mimics the subtle glass edge found in iOS UI elements.

##### Bevel Effect

- Open **3D Format**
- Add a top bevel around **20–30**
- Adjust height slightly for curvature

##### Shadow

- Use a centered shadow preset
- Increase blur and size
- Use a soft gray or subtle black

These effects add depth without distracting from the data.

##### Step 7: Align Panels with Your Report Layout

Bring in your screenshot reference:

- Send it backward behind the shapes
- Align each glass panel to match existing visuals
- Duplicate shapes as needed for cards, charts, tables, and maps

Once aligned, remove the reference image.

##### Step 8: Export the Slide as an Image

To use the background in Power BI:

1. Save the PowerPoint file
2. Choose **Save As**
3. Select an image format such as **JPEG or PNG**
4. Save **only the current slide**

This image becomes your Power BI report background.

##### Step 9: Apply the Background in Power BI

In Power BI:

- Duplicate your report page
- Open **Format > Canvas Background**
- Browse and upload the image
- Set Image Fit to **Fill or Stretch**

Once applied:

- Adjust visual backgrounds
- Update text colors
- Ensure all visuals remain readable

Small tweaks go a long way in making the glass effect feel intentional and professional.

##### When to Use the Glass Look (and When Not To)

This style works best when:

- You want a modern, visually engaging report
- The audience values presentation and polish
- The report is not overly dense with visuals

It may not be ideal for:

- Highly data-dense operational dashboards
- Reports requiring maximum contrast
- Environments with strict accessibility requirements

As with any design trend, use it selectively.
