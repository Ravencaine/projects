# Each Layer Must Have Distinct Responsibility

<!-- A layer is only justified when it has a distinct, unambiguous responsibility that no other layer handles; if no one is hurt by removing it, it may not need to exist. -->

## Claim

A layer is only justified when it has a distinct, unambiguous responsibility that no other layer handles; if no one is hurt by removing it, it may not need to exist.
