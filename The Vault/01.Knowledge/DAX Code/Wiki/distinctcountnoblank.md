# DISTINCTCOUNTNOBLANK

## Remarks

Unlike DISTINCTCOUNT function, DISTINCTCOUNTNOBLANK does not count the BLANK value. This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
