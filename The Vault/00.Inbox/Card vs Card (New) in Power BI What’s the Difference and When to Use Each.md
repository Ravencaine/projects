Power BI is constantly evolving, and one of the subtle but powerful changes is the introduction of the “Card (New)” visual. If you’ve ever used the standard Card visual to display KPIs or single values, it’s time to explore what’s new and why it matters.

## 🔍 What Is a Card Visual?

The Card visual in Power BI is used to display a single metric — such as total sales, customer count, or revenue growth. It’s perfect for quick KPIs where you just need to show one value with a label.

## 🆕 What’s New in Card (New)?

Microsoft introduced “Card (New)” to address the limitations of the classic card. It includes:

- ✅ Modern look and feel
- 🎨 Advanced formatting options
- 🔁 Conditional formatting on text and background
- 🧠 Support for Copilot and on-object interaction
- ⚙️ Dynamic layout control
![](https://miro.medium.com/v2/resize:fit:1400/format:webp/0*VxyVFTjJxSmwtxIp)

## 💡 When Should You Use Which?

## ✔️ Use Classic Card When:

- You want a simple, fast-loading visual.
- Formatting is not a high priority.
- Your dashboard focuses on performance over design.

## 🌟 Use Card (New) When:

- You need a professional, polished design.
- You want to apply conditional formatting.
- You’re using Copilot or on-object editing features.
- You want better alignment and layout control.

## ⚙️ How to Enable “Card (New)” in Power BI

1. Go to File → Options and settings → Options.
2. Navigate to Preview Features.
3. Check “New Card Visual”.
4. Restart Power BI Desktop.

*While both visuals have their place, Card (New) is a must-use for modern Power BI reports that need flexibility, design finesse, and interactivity. If you haven’t tried it yet, enable it today and level up your dashboard game!*
