# T.INV

Applies to: Calculated column Calculated table Measure Visual calculation Returns the left-tailed inverse of the Student's t-distribution.

## Syntax

```dax
T.INV(Probability,Deg_freedom)
```

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
