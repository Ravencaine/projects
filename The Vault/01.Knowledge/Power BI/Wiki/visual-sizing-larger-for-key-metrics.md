# Visual Sizing — Larger for Key Metrics

Use larger visual sizes to signal importance and draw the eye to the most critical metrics.

## Principle

Visual size is a direct proxy for importance. The largest elements on a page are read first. Reserving large canvases for KPIs and primary metrics — and using smaller sizes for supporting or exploratory visuals — creates a clear hierarchy of attention. This principle aligns with [[Visual-Information-Seeking-Mantira]]: overview first, details on demand.

## Guidelines

- Reserve the largest visuals for headline KPIs (revenue, margin, churn rate)
- Maintain consistent sizing for visuals of the same type to enable fair comparison (e.g., all bar charts the same width)
- Do not use large sizes for purely decorative elements — size must correspond to informational weight
