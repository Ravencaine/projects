# Type.ListItem

Returns an item type from a list type.

## Signature

```m
Type.ListItem(type as type) as type
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| type | type | |

## Returns

type

### Example 1

Find item type from the list {number}.

```m
Type.ListItem(type {number})
```

// Output
```
type number
```
