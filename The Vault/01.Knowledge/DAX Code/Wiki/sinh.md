# SINH

Applies to: Calculated column Calculated table Measure Visual calculation Returns the hyperbolic sine of a number.

## Syntax

```dax
SINH(number)
```

## Remarks

The formula for the hyperbolic sine is: ez − e−z SINH(z) = 2 This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
