# Conditional Formatting in Power BI (Van Wyk / Data Bear)

A Data Bear blog post by Annamarie Van Wyk covering the basics of Power BI's built-in conditional formatting feature for tables and matrices — background color, font color, data bars, icons, and web links.

## Summary

An entry-level guide to Power BI's built-in conditional formatting for table and matrix visuals. Covers the five formatting types (background color, font color, data bars, icons, web links), the step-by-step workflow for applying rules via the Format pane → Cell elements → fx dialog, and practical examples (sales performance, KPI tracking, clickable web links). The article emphasizes the dynamic nature of conditional formatting — rules persist as data changes.

## Key Claims

- Conditional formatting is applied via Format pane → Cell elements → type → fx
- Available types: Background Color, Font Color, Data Bars, Icons, Web URL
- Rule types: Rules (static thresholds), Field value (from DAX measure), Percentile
- Multi-Row Card and Card visuals do not support conditional formatting — requires a DAX workaround
- Web URL conditional formatting turns text columns into clickable hyperlinks
