## Why Zero Gap Width

A histogram shows frequency distribution — bars should touch to represent continuous bins. Standard column charts have gaps by default; set Gap Width = 0 to remove them.

## Pivot Table Histogram vs. Analysis ToolPak Histogram

| Feature | Pivot Table | Analysis ToolPak |
|---------|------------|-----------------|
| Bins | Manual control | Manual or auto |
| Formatting | Full chart customization | Limited |
| Integration | Can slice by other dimensions | Standalone output |
| Automation | Refreshes with data | Static |
