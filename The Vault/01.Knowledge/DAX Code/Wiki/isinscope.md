# ISINSCOPE

Applies to: Calculated column Calculated table Measure Visual calculation Returns true when the specified column is the level in a hierarchy of levels.

## Syntax

```dax
ISINSCOPE(<columnName>)
```

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
