# Excel.CurrentWorkbook

Returns the contents of the current Excel workbook. It returns tables, named ranges, and dynamic arrays. Unlike Excel.Workbook, it does not return sheets. --- PAGE 351 ---

## Signature

```m
Excel.CurrentWorkbook() as table
```

## Returns

table
