# Normalized Tables

<!-- A database design approach using separate tables for distinct entities (customers, orders, payments) with foreign key relationships. Designing normalized tables exposes duplicate records, inconsistent formatting, and missing relationships that flat-row spreadsheets hide. -->

## Definition

A database design approach using separate tables for distinct entities (customers, orders, payments) with foreign key relationships. Designing normalized tables exposes duplicate records, inconsistent formatting, and missing relationships that flat-row spreadsheets hide.
