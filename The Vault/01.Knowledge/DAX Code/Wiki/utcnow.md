# UTCNOW

Applies to: Calculated column Calculated table Measure Visual calculation Returns the current UTC date and time.

## Syntax

```dax
UTCNOW()
```

## Remarks

The result of the UTCNOW function changes only when the formula is refreshed. It is not continuously updated.
