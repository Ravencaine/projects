# Number.Power

Returns the result of raising number to the power of power. If number or power are null, Number.Power returns null. number: The base. power: The exponent. Example Find the value of 5 raised to the power of 3 (5 cubed). Usage Power Query M Number.Power(5, 3) Output 125 Last updated on 03/24/2026 --- PAGE 852 ---
