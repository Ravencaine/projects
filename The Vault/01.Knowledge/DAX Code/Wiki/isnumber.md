# ISNUMBER

Applies to: Calculated column Calculated table Measure Visual calculation Checks whether a value is a number, and returns TRUE or FALSE.

## Syntax

```dax
ISNUMBER(<value>)
```

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules. This function is an alias of ISNUMERIC.
