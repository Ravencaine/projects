# ODDLYIELD

Applies to: Calculated column Calculated table Measure Visual calculation Returns the yield of a security that has an odd (short or long) last period.

## Syntax

```dax
ODDLYIELD(<settlement>, <maturity>, <last_interest>, <rate>, <pr>, <redemption>, <frequency>[, <basis>])
```
