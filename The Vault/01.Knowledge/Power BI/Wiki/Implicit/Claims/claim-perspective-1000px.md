# perspective: 1000px is the standard CSS value for natural-looking 3D card rotation

<!-- Setting .flip-card { perspective: 1000px; } creates a 3D depth environment where the 1000px distance produces a natural-feeling rotation. Using smaller values warps the transform; larger values flatten the effect. -->

## Claim

Setting .flip-card { perspective: 1000px; } creates a 3D depth environment where the 1000px distance produces a natural-feeling rotation. Using smaller values warps the transform; larger values flatten the effect.
