# AI in Excel: Three Feature Tiers

Excel's AI capabilities fall into three distinct tiers, each with different use cases and requirements.

## Definition

AI in Excel is delivered through three separate mechanisms: built-in intelligent features (Flash Fill, Analyze Data), Copilot for conversational formula and chart generation, and Python in Excel for advanced data science. Each tier serves different tasks and has different subscription/platform requirements.

## Key Points

- **Built-in features** (Flash Fill, Analyze Data) are available to all Excel users with no additional subscription and are sufficient for routine data cleanup and pattern recognition.
- **Copilot in Excel** requires a Microsoft 365 Copilot license; it drafts formulas, explains existing ones, builds charts, and summarizes data from natural-language prompts.
- **Python in Excel** requires Microsoft 365 Copilot and is available on a rolling basis by platform — availability depends on subscription type and whether you are on Windows, Mac, or web.
- The three tiers are not interchangeable. Built-in features cover simple cleanup tasks; Copilot handles formula drafting and summarization; Python handles forecasting, statistical modeling, and advanced visualization.
- AI performs best when the workbook has a solid foundation: structured data, clear headers, inputs separated from calculations, and defined expected outputs.

## Examples

| Task | Best AI tier |
|------|-------------|
| Auto-complete a column of product codes from examples | Flash Fill |
| Suggest a chart based on selected data | Analyze Data |
| Draft a COUNTIF summary formula | Copilot |
| Build a Gantt chart from a task list | AI-assisted charting tools |
| Forecast revenue from historical data | Python in Excel |
| Clean up messy task names | Flash Fill or Copilot |
