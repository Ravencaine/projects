# EARLIEST

## Syntax

```dax
EARLIEST(<column>)
```

## Remarks

The EARLIEST function is similar to EARLIER, but lets you specify one additional level of recursion. This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
