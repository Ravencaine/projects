# FIRSTNONBLANK

Applies to: Calculated column Calculated table Measure Visual calculation ７ Note

## Syntax

```dax
FIRSTNONBLANK(<column>,<expression>)
```

## Return Value

meaningless results. Returns the first value in the column, column, filtered by the current context, where the expression is not blank. Syntax DAX FIRSTNONBLANK(<column>,<expression>) Parameters ﾉ Expand table Term Definition column A column expression. expression An expression evaluated for blanks 

## Remarks

The column argument can be any of the following: A reference to any column. A table with a single column.
