# Separating data from UI components makes the UI reusable and data source swappable

<!-- Loading data at startup from CSV/API/database and passing it into components as arguments means changing the data source requires changing one loader function, not every component. This mirrors Power BI binding visuals to a model rather than hardcoding static values. -->

## Claim

Loading data at startup from CSV/API/database and passing it into components as arguments means changing the data source requires changing one loader function, not every component. This mirrors Power BI binding visuals to a model rather than hardcoding static values.
