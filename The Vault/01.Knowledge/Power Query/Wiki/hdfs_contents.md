# Hdfs.Contents

Returns a table containing a row for each folder and file found at the folder URL, url, from a Hadoop file system. Each row contains properties of the folder or file and a link to its content. --- PAGE 360 ---

## Signature

```m
Hdfs.Contents(url as text) as table
```

| Parameter | Type | Description |
|-----------|------|-------------|
| url | text | |

## Returns

table
