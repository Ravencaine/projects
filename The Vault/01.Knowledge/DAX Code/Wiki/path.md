# PATH

Applies to: Calculated column Calculated table Measure Visual calculation Returns a delimited text string with the identifiers of all the parents of the current

## Syntax

```dax
PATH(<ID_columnName>, <parent_columnName>)
```

## Return Value

the items that are related to the current row value. For

## Remarks

This function is used in tables that have some kind of internal hierarchy, to return the items that are related to the current row value. For
