# ADDMISSINGITEMS

Applies to: Calculated column Calculated table Measure Visual calculation Adds rows with empty values to a table returned by SUMMARIZECOLUMNS.

## Remarks

This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
