# COSH

Applies to: Calculated column Calculated table Measure Visual Returns the hyperbolic cosine of a number.

## Syntax

```dax
COSH(number)
```

## Remarks

The formula for the hyperbolic cosine is: ez + e−z COSH(z) = 2 This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
