# Grid Alignment — Structured Layout

Align dashboard elements horizontally and vertically, using a grid system to enforce consistent spacing and balance.

## Principle

Alignment creates visual order. When elements share an edge or axis, the eye perceives them as related and organized. Misaligned elements — even slightly off-grid — create subconscious unease and signal lack of polish. A grid system enforces consistent spacing automatically, making alignment a habit rather than a manual effort.

## Guidelines

- Use Power BI's built-in grid snap to align visuals precisely
- Align elements by their primary edges (left, right, top, bottom, or center)
- Consistent spacing: use a base unit (e.g., multiples of 8px) for all gaps
- The grid reinforces [[Visual-Design-Principles]] — balance and structure across the page
