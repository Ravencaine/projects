# DAX Sample Model: Adventure Works DW 2020

The Adventure Works DW 2020 Power BI Desktop sample model is designed to support DAX learning. The model is based on the Adventure Works data warehouse sample for AdventureWorksDW2017 - with modifications to suit the objectives of the sample.

## Model Structure

The model contains:
- **Fact tables**: Internet Sales, Reseller Sales
- **Dimension tables**: Customer, Product, Date/Calendar, Geography, Sales Territory, Employee
- **Measures**: Total Sales, Total Cost, Profit, Profit Margin, Order Count

## Using the Sample Model

Use this model to:
- Practice DAX formulas and measures
- Understand filter context by building PivotTables
- Practice time intelligence calculations
- Explore CALCULATE and filter propagation
- Practice iterator functions (SUMX, MAXX, etc.)

## Where to Get It

Available from Microsoft as a free download: "Adventure Works DW 2020 Power BI Desktop"
