# Information Architecture (Report Design)

Organizing information requirements into key themes with associated data needs before building a report — the prerequisite step before any sketching or visual design.

## Key Principle

Start with user requirements and documentation, not with the data. Explicitly specify key themes, then list the type of information needed under each.

## Why It Matters

Prevents dashboard sprawl — when you know the themes first, each visual earns its place by serving a specific information need rather than being added reactively.
