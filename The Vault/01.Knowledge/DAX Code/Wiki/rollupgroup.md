# ROLLUPGROUP

Applies to: Calculated column Calculated table Measure Visual Modifies the behavior of the SUMMARIZE and SUMMARIZECOLUMNS functions by adding rollup rows to the result on columns defined by the the groupBy_columnName

## Remarks

ROLLUPGROUP can only be used as a groupBy_columnName argument to ROLLUP, ROLLUPADDISSUBTOTAL, or ROLLUPISSUBTOTAL.
