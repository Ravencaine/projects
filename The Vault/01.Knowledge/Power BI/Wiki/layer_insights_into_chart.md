# Layer Insights Directly Into the Chart

<!-- use DAX measures to generate narrative annotations that appear inside or alongside the chart visual -->

## Definition

DAX measures can generate narrative text (insights, explanations, calls to action) that is rendered inside the chart area — via shapes, text boxes, or the Smart Narrative visual — making the insight inseparable from the data it describes.

## Key Points

- DAX-generated insight text can be placed inside or alongside the visual for tight coupling of insight and data
- AI tools (Copilot, ChatGPT) can accelerate the DAX logic for complex insight generation
- This transforms a static chart into a guided analytical experience
- Examples: "Sales in Q3 exceeded target by 12% — driven by APAC region" rendered as an annotation on the chart
