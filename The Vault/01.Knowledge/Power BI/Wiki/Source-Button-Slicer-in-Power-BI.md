# Discover the Power of the New Button Slicer in Power BI (Data Bear)

> **Type:** article
> **Author:** Boniface Muchendu
> **Published:** 2024-10-26
> **URL:** https://databear.com/exploring_new_button_slicer_power_bi/
> **Routed to:** Power BI

## Summary

Button Slicer is a native Power BI slicer type (November 2023+) that renders field values as clickable buttons with hover/selected states. Supports image integration, shape customization, single/multi-select, and callout values.

## Key Claims

- Native slicer type — no AppSource/custom visual needed
- Add via Visualizations pane → button slicer icon
- Fields must have URL data category set for image display
- Shape options: rectangle or rounded rectangle
- Layout: rows/columns grid, or single-row with overflow (scroll or pagination)
- Single vs multi-select configurable
- Button states: Default, Hover, Selected
- Callout values: customize what shows when selected/hovered/pressed
- Effects: shadows, glow, borders
- Image fit options for button backgrounds
