# ERROR

Applies to: Calculated column Calculated table Measure Visual Raises an error with an error message.

## Syntax

```dax
ERROR(<text>)
```

## Remarks

The ERROR function can be placed in a DAX expression anywhere a scalar value is expected. This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
