# ROUND

## Syntax

```dax
ROUND(<number>, <num_digits>)
```

## Remarks

If num_digits is greater than 0 (zero), then number is rounded to the specified number of decimal places. If num_digits is 0, the number is rounded to the nearest integer. If num_digits is less than 0, the number is rounded to the left of the decimal point. Ties are broken by rounding half away from zero (also known as commercial rounding). |
