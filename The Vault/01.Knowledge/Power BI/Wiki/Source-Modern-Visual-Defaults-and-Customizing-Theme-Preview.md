# Modern Visual Defaults and Customizing Theme (Preview)

> **Type:** Fabric Community blog / product update
> **Author:** Microsoft Fabric team
> **Published:** 2026-07-21
> **URL:** community.fabric.microsoft.com/t5/Power-BI-Updates-Blog/...
> **Routed to:** Power BI

## Summary

Power BI preview feature: modern visual defaults (Fluent 2 design system) + new "Customize theme" formatting pane for report-wide styling without touching individual visuals. Covers theme settings, color palettes, text styles, visual properties, page settings, and filter pane — all in one pane. Theme JSON editing in VS Code with Copilot and schema support.

## Key Claims

- Enable: File → Options → Preview features → "Modern visual defaults and customizing theme improvements"
- Theme settings: import/export custom report JSON, name customizations, pick base theme, Save base theme selection toggle
- Colors: brand colors in color picker, built-in palettes, data colors / structural colors / sentiment colors / divergent colors — all adjustable report-wide
- Text: style title, callout, label, general text across report; new visuals inherit automatically; Reset to base theme option
- Visual properties: background, border, corner rounding, shadow, padding, header icons, tooltip styling — apply to all new and existing visuals at once
- Page: default new page size, wallpaper, background color/transparency across all pages; existing pages update on reset to default
- Filter pane: text, input boxes, headers, search, borders, backgrounds, filter cards — report-wide
- Update theme: check for updated base theme; Apply latest default styles button; existing reports don't auto-update
- Undo: CTRL+Z or arrows at top-left work during theme customization
- Theme JSON schema: [github.com/microsoft/powerbi-desktop-samples/tree/main/Report Theme JSON Schema](https://github.com/microsoft/powerbi-desktop-samples/tree/main/Report%20Theme%20JSON%20Schema)
- Themes dropdown: color-only themes moved to new Color palettes section; built-in themed reports remain in Themes dropdown
- Clear theme to return to visual defaults
