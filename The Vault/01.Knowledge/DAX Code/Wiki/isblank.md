# ISBLANK

Applies to: Calculated column Calculated table Measure Visual calculation Checks whether a value is blank, and returns TRUE or FALSE.

## Syntax

```dax
ISBLANK(<value>)
```

## Remarks

To learn more about best practices when working with BLANKS, see Avoid converting BLANKs to values in DAX.
