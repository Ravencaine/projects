# Remove Non-Value Elements from Charts

<!-- remove axis titles, data labels, gridlines that don't serve a clear purpose — reduce visual noise -->

## Definition

Remove any chart element that does not directly serve the user's comprehension of the data. If removing it would not reduce insight, it should be removed.

## Key Points

- Turn off axis titles when the axis is self-evident (e.g., department names, months)
- Turn off gridlines unless they are needed to read precise values
- Turn off data labels unless specific values are being highlighted
- Match fonts, colors, and backgrounds to the overall report theme
- Small visual clean-ups make a chart feel clearer and more polished

## Examples

- A column chart showing turnover by department: department labels on the X-axis are self-documenting — axis title "Department" adds no value, remove it
- A line chart with monthly data: Y-axis values and date labels on the X-axis already convey what is being measured — a generic title "Turnover Rate" is redundant
