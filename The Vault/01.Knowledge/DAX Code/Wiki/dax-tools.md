# DAX Tools

## Built-in Tools

### Power BI Desktop
- Formula bar with AutoComplete for writing DAX formulas
- DAX Editor for calculated tables and calculated columns
- Best for modelers and report authors

### Power Pivot in Excel
- Formula bar for DAX formulas
- More limited than Power BI

### SQL Server Management Studio (SSMS)
- DAX query editor for Analysis Services
- Query both tabular and multidimensional models
- Essential for server-level administration

## Third-Party Tools

### DAX Studio (Open Source)
Free, feature-rich client for creating and running DAX queries against Analysis Services, Power BI Desktop, and Power Pivot.

Features: Query Editor, IntelliSense/Autocomplete, Code Formatting, Query Plans, Server Timings, Export to CSV/Clipboard

### Tabular Editor (Open Source)
- Advanced model authoring without going through the UI
- Scripting support (C# scripts)
- Best Practice Analyzer
- DAX script editing with validation

### DAX Formatter (daxformatter.com)
- Free web tool
- Paste DAX code and get properly formatted version
- Essential for readable code
