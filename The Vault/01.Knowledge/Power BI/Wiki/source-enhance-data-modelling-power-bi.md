# Enhance Data Modelling in Power BI

Boniface Muchendu · Data Bear · databear.com · 2024-03-31

## What this article covers

Practical Power BI data modeling tips: creating a centralized measures repository table, organizing measures with display folders, preventing auto-aggregation with Summarize by None, and using model view features for large models.

## Techniques covered

1. **Measures repository:** `_Measures` table with `Hide Me` column created via Enter Data; move existing measures via Home Table property
2. **Display folders:** organize measures into named folders in model view
3. **Summarize by None:** prevent fields like Calendar Year from auto-summarizing
4. **Model view features:** Show related fields, separate tabs for large models
