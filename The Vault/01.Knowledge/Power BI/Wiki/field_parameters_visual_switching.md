# Field Parameters for Visual Switching

<!-- use field parameters to let users switch what a single visual displays — avoid duplicating visuals -->

## Definition

A single visual can serve multiple analytical purposes by using field parameters, allowing users to switch the breakdown dimension (e.g., department, geography, tenure band) without needing separate copies of the same visual.

## Key Points

- Field parameters eliminate the need to duplicate a visual for each breakdown dimension
- Conditionally format column/row colors based on the selected parameter to make dimension switches obvious
- This is the Power BI equivalent of a slicer — but the user controls the breakdown axis directly on the visual
- One visual, multiple purposes — reduces report clutter and empowers self-service exploration

## Examples

A turnover chart with a field parameter letting users switch between:
- By Department
- By Geography
- By Tenure Band

The column colors update to reflect which dimension is active.
