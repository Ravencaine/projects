# PNG Background Behind Chart

Place a PNG image behind a native Power BI chart to create custom visual styling. The chart's own background is turned off so the PNG shows through — enabling modern, brand-consistent designs without custom visuals.

## How to Add

1. Create the background image (Figma, Canva, or download)
2. Export as **PNG** (transparent or opaque as needed)
3. In Power BI: **Insert** → **Image** → select the PNG file
4. Resize and position the image to cover the chart's plot area
5. Select the image → **Bring to back** so it sits behind the chart

## Chart Formatting

- Select the chart → **Format** pane → **Background** → **Off**
- This is critical: if the chart background is on, it covers the PNG

## Design Options

| Tool | Use |
|------|-----|
| Figma | Custom oblique/gradient backgrounds, brand-matched styling |
| Canva | Quick branded backgrounds |
| Web images | Free gradient/pattern backgrounds |
| Screenshot | Capture specific visual styles from other dashboards |

## Use Cases

- Oblique/angled backgrounds (healthcare, tech aesthetics)
- Brand-coloured chart backgrounds
- Subtle texture or gradient effects
- Fictional/metro-style map backgrounds behind geo-charts
