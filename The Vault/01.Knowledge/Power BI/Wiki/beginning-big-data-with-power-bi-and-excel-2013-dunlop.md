# Beginning Big Data with Power BI and Excel 2013

**Neil Dunlop · Apress · 2015 · 258 pages**

## Source Overview

Comprehensive introduction to Microsoft's BI and big data tools as of 2013-2015:
- Excel PowerPivot (in-memory data model)
- Power Query (ETL and data shaping)
- DAX (measures, calculated columns, KPIs)
- Power View (interactive visualizations)
- Power Map (geospatial 3D visualizations)
- Azure HDInsight (Hadoop in the cloud)
- Excel Analysis ToolPak (descriptive and inferential statistics)
