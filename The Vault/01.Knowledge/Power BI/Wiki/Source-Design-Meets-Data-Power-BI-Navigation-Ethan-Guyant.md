## Summary

Tutorial on using Power BI's native Page Navigator component for report navigation, with a comparison table covering three approaches: Figma (image import), Native shapes + buttons, and Page Navigator. Includes detailed formatting steps for the Page Navigator's four states (Default, Hover, Press, Selected) with exact font, colour, and fill values.

## Key Claims

1. Page Navigator is a native feature requiring minimal setup and auto-updates when pages are added
2. Navigation pane height = number of pages × 35px; navigator width = 130px, positioned at x=10, y=100
3. Page Navigator's Selected state uses a right-side accent bar (6px, accent green #6CBE4B) to indicate the active page
4. Figma approach is fastest to load (pre-rendered image) but highest maintenance
5. Page Navigator is lowest maintenance but most limited design flexibility
6. The Design Meets Data series covers three navigation approaches across three articles
