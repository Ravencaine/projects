# ISERROR

Applies to: Calculated column Calculated table Measure Visual calculation Checks whether a value is an error, and returns TRUE or FALSE.

## Syntax

```dax
ISERROR(<value>)
```

## Remarks

For best practices when using ISERROR, see Appropriate use of error functions. This function is not supported for use in DirectQuery mode when used in calculated columns or row-level security (RLS) rules.
