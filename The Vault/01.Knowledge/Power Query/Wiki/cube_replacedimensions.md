# Cube.ReplaceDimensions

Replaces the set of dimensions returned by Cube.Dimensions. For example, this function can be used to add an ID column to a dimension attribute, so that the data source can group on the ID rather than the displayed value. Last updated on 04/03/2026 --- PAGE 344 ---

## Signature

```m
Cube.ReplaceDimensions(cube as table, dimensions as any) as table
```

| Parameter | Type | Description |

| cube | table | |
| dimensions | any | |
